## 初步判讀
- U-oof 比方法一 1B 保守：特異度略高，但敏感度低 0.14、漏寫多；等於在 t_f1 之上又加了更高的門檻。
- 提示為陰性時 LLM 幾乎照寫，影像 token 沒有把漏掉的陽性補回來。
- 骨質減少漏寫 93%；腎水腫側別正確 22%、骨折椎體節段 9%，屬性仍弱。
- U-gt（真實標籤＋dropout 訓練提示）：macro 敏感度 0.479 → 0.600、F1 0.571 → 0.655，關鍵錯誤率 29.4% → 23.1%；和 DCP-PD 的方向一致。
- 但 U-gt 幾乎完全照提示寫：自然 FN 提示一致率 0.7%（422 格）、自然 FP 提示 7.3%（302 格），等於把分類器在 t_f1 的判斷轉成句子；F1 與方法一 1B 相當（0.655 vs 0.665）。
- U-gt 漏寫仍多（11.8%，方法一 1B 3.8%）：骨質減少 50%、腹腔游離氣體 46%、骨折 32%。關鍵錯誤＋漏寫合計 34.9%，方法一 1B 32.0%。
- U-gt 風格：ROUGE-L 0.451、BERTScore F 0.896、BLEU-4 0.193。
- T-oof（只用文字、OOF 提示）：macro 敏感度 0.454、F1 0.546、關鍵錯誤 29.8%、漏寫 14.0%；micro F1 0.654 與 U-oof 相同。U-oof 比 T-oof macro F1 只高 0.025（600 例、未做 CI），自然 FN 提示一致率 T-oof 3.6% vs U-oof 2.1%：在 OOF 設定下，單元影像 token 的貢獻很小。
- T-oof 風格：ROUGE-L 0.450、BERTScore F 0.896、BLEU-4 0.223。
- T-gt（只用文字、真實標籤＋dropout 訓練提示）：macro 敏感度 0.605、特異度 0.954、F1 0.658、micro F1 0.698；關鍵錯誤 24.7%、漏寫 9.7%（合計 34.4%）。漏寫：骨質減少 50.0%、腹腔游離氣體 42.9%、骨折 34.0%。屬性：腎水腫側別 43.2%、骨折椎體節段 2.3%。
- T-gt 風格：ROUGE-L 0.453、BERTScore F 0.896、BLEU-4 0.207。
- T-gt vs U-gt（gt 設定下單元影像 token 有沒有幫助？）：macro F1 0.658 vs 0.655、micro F1 都是 0.698、敏感度 0.605 vs 0.600，差距都在 0.01 以內（600 例、未做 CI）；自然 FN 提示一致率兩組都是 0.7%（422 格）。關鍵錯誤 T-gt 略高（24.7% vs 23.1%）、漏寫略低（9.7% vs 11.8%），合計幾乎相同（34.4% vs 34.9%）。結論：gt 設定下影像 token 同樣沒有可見貢獻，和 OOF 設定一致。
- T-gt vs T-oof（純文字下 gt＋dropout 訓練的效果）：macro F1 0.546 → 0.658（+0.112）、敏感度 0.454 → 0.605、關鍵錯誤 29.8% → 24.7%、漏寫 14.0% → 9.7%，幅度和 U 組（U-oof → U-gt）相當。代價是更照提示寫：自然 FP 提示一致率 47.7% → 5.3%（302 格），自然 FN 3.6% → 0.7%。
- U-gt 翻轉 vs U-oof 翻轉（gt＋dropout 訓練是否讓模型更盲從提示？）：是。提示翻成陰性時原陽性仍寫對 6.5% → 1.6%（29/446 → 7/446），提示翻成陽性時原陰性仍寫對 38.0% → 12.8%（128/337 → 43/337）。U-oof 的「抗錯誤提示」主要在陰→陽方向（會不理部分假陽性提示），U-gt 幾乎全照提示寫；這也解釋了 U-gt 一般推論的 F1 提升：分類器在 t_f1 的提示整體比模型自行修正更可靠，模型越照寫，F1 越接近方法一 1B 樣板。
- 目前四組中沒有一組明顯超過方法一 1B 樣板（macro F1 0.665）；gt 組漏寫仍是樣板的 2.5 倍以上。
- 單元影像 token 有沒有讓模型抵抗錯誤提示？沒有。OOF 設定：U-oof vs T-oof，陽→陰 6.5% vs 8.3%、陰→陽 38.0% vs 38.6%，翻轉後 macro F1 0.351 vs 0.358，純文字組甚至略高。gt 設定：U-gt vs T-gt，1.6% vs 1.1%、12.8% vs 11.0%，macro F1 0.389 vs 0.388。兩種設定下差距都在幾個病例之內（600 例、未做 CI）。
- gt＋dropout 訓練在純文字組也讓模型更照提示寫：T-oof → T-gt，陽→陰 8.3% → 1.1%、陰→陽 38.6% → 11.0%，幅度和 U 組（6.5% → 1.6%、38.0% → 12.8%）相同。所以「更盲從提示」來自訓練時給的提示品質（真實標籤），和有沒有影像 token 無關。
- 腹主動脈瘤 不理假陽性提示（26/31）在 U-gt、T-oof、T-gt 都出現，純文字組也有，所以不是影像 token 的作用；原因待查（可能和提示中其他文字資訊有關）。
- OOF 組對假陽性提示的「抵抗」（約 38%）在純文字組一樣存在，表示這是 OOF 提示訓練學到的「提示不完全可信」的語言先驗，不是看圖修正。

## 四組結論（600 例）
四組比較下，單元影像 token 在一般推論和錯誤提示測試都沒有可見貢獻：U 與 T 在同一提示設定下的 macro F1、關鍵錯誤率、錯誤提示一致率差距都很小（600 例、未做 CI）。決定結果的是訓練時的提示來源：gt＋dropout 讓 F1 提升 0.08–0.11、關鍵錯誤降 5–6 個百分點，但模型幾乎完全照提示寫（假提示下仍寫對只剩 1–13%），等於把分類器在 t_f1 的判斷轉成句子，F1 追平但沒有超過方法一 1B 樣板（0.665），漏寫仍是樣板的 2.5 倍以上。OOF 組保留較多「不照提示」的空間，但這部分在純文字組一樣存在，不是看圖。完整 val（5,055 例）推論已完成，評估待做；正式結論以完整 val 為準。

- 和 val600 一樣，完整 val 的 macro F1 比 val600 低約 0.05（1B 0.665 → 0.615，U-gt 0.655 → 0.607），組間排序不變。

## 改進項 1：強制寫滿 14 類（agent E，`method4/fill14.py`；不用 GPU）
- 做法：原生成的 Qwen 反抽為 not_mentioned 的類別（漏寫），依該例當時餵給模型的提示補方法一 1B 樣板句：提示 ≥ 門檻（t_f1）→ 陽性樣板句；< 門檻 → 陰性樣板句。和方法一相同：動脈粥狀硬化、骨質減少在陰性時不寫；沒有分數的類別不補；同一器官群組全部要補且句庫有聯合句時用聯合句；腹主動脈瘤、脾腫大的陽性句帶分割量測值（train 線性校正）。
- 補的量（val600）：每組 593–599 例有補；陰性句 1,555–1,614 格；陽性句 U-oof 121、T-oof 129、U-gt 30、T-gt 11 格（OOF 組較常不理陽性提示）。完整 val：U-gt 陽 143／陰 12,376，T-gt 陽 67／陰 12,471。

### 判讀
- 漏寫幾乎消失（gt 組 9.7–11.8% → 3.7–3.8%，完整 val 10–11% → 4.8%），剩下的漏寫主要是動脈粥狀硬化、骨質減少：提示為陰性時，照方法一的規則不補句子。
- 但漏寫的原陽性多數當時的提示是陰性，補上後變成寫陰性：關鍵錯誤 +5～6 個百分點，「關鍵錯誤＋漏寫」gt 組幾乎不變（完整 val 34.7% → 33.7%、34.6% → 34.1%），macro F1 只變 +0.003～0.004。
- OOF 組獲益較大（macro F1 +0.04～0.05，合計 −5 個百分點），因為它們常不寫陽性提示的類別；補上陽性句等於把它們拉回照提示寫。
- 補滿後四組都收斂到方法一 1B 的水準（val600 gt 組 macro F1 0.656–0.659 vs 1B 0.665，漏寫 3.7–3.8% vs 3.8%），沒有超過 1B。BLEU-4 上升約 0.04（樣板句和醫師常見寫法相同），ROUGE-L 下降約 0.015，BERTScore 不變。
- 結論：強制寫滿是有效的安全網（不再漏寫），但不會提高疾病判定的正確率；要減少關鍵錯誤，還是要靠更好的提示（分類器、偏敏感度門檻），不是靠寫滿。

### 快速代理評估（agent G，`improve/proxy_eval.py`；只用 CPU，每組約 10 秒，不呼叫 Qwen）
- 做法：用 B 的規則（`targets/mt_lib.py`：段落群組、關鍵字、NegEx、屬性規則）從生成文字抽 14 類狀態與屬性，其餘直接沿用 `evaluate.py`（同一份參考標籤、owl 定義、嚴格模式、關鍵錯誤、漏寫、屬性、錯誤提示測試、BLEU／ROUGE-L；不算 BERTScore）。模型輸出的器官段落標題（例如腎臟段落標題）照真實報告的段落群組處理。另加 6 條「Qwen 判讀規則」：腸胃段落寫 Normal → 闌尾炎陰性；腹部＋骨盆少量積液 → 腹水陽性；局部脂肪浸潤 → 脂肪肝陽性；pars 缺損、具名骨頭變形 → 骨折陽性；腹主動脈瘤 < 3.0 cm → probably_no；陽性病例的 yes/no 屬性沒寫到 → no。
