# Pillar-0 × OWL on Merlin：Option A 結果（val）


2026-11-11｜Pillar-0（Pillar0-AbdomenCT）特徵：CT-rate 抽取 train＋val 20,364 例，0 例失敗。分析在 A6000 只用 CPU 跑。
程式在 `pillar/optionA/`（pack_feats.py 在 CT-rate 執行，其餘在 A6000）。結果檔在 A6000 `~/Desktop/Tony/VLM/OWL/pillar_optA/out/`（含病例 id，不進 git）。

## 結論（先讀這段）
- **14 類疾病偵測：Pillar 只帶來很小的增益。** OWL+Pillar 堆疊在 8/14 類達顯著（腹水 +.012、膽管擴張 +.010、腸阻塞 +.010、
  腹腔游離氣體 +.007、腎水腫 +.004、膽囊已切除 +.003、脾腫大 +.001、動脈粥狀硬化 +.001）。其餘 6 類無差異，沒有任何一類變差。
  單用 Pillar（不論 global 或器官單元）每一類都 ≤ OWL，只有腹水、腸阻塞的器官單元版與 OWL 打平。
  增益都 ≤ .012 AUROC，而且 14 類同時檢定，沒有做多重比較校正。
- **屬性：Pillar 的價值主要在這裡。**
  - 腎水腫側別：Pillar vec16 單用的每腎 AUROC 為 .952，OWL 單元是 .939（差異不顯著）。OWL+Pillar 達 .955（Δ +.016，顯著），
    病例側別完全正確率從 .715 升到 .770（Δ +.056，顯著）。
  - 骨折節段：Pillar 單用比 OWL 差（每節 .888 vs .929，top-1 .684 vs .750）。堆疊後每節 AUROC 只多 +.005；
    OWL+Pillar+M4 的 top-1 比 OWL+M4 多 +.020（.786 vs .766，顯著）。
  - 分級屬性：Pillar 器官單元在脂肪肝分級（.940 vs OWL 類別分數 .870）、腹水量（.885 vs .859）、動脈粥狀硬化程度
    （.911 vs .904，不顯著）上都比較好，堆疊在三項都顯著。注意：這裡的 OWL 對照只是「該疾病的類別機率」，不是 OWL 的
    embedding probe，所以對 OWL 不完全公平。
  - 測量型屬性（AAA 直徑、脾臟長度）：Pillar 不如分割量測，堆疊也沒有增益。
- **Option B（把 Pillar token 直接餵給 LLM）建議：目前不值得做完整版。** 疾病有無的增益太小，不值得重訓 projector／LoRA。
  有用的訊號集中在側別和分級，而這些可以用更便宜的方式帶進方法四：把「OWL+Pillar 堆疊」的每腎、每節分數，以及
  脂肪肝、腹水、動脈粥狀硬化的分級 probe 分數，寫進 prompt 的結構化 cue 行（沿用同儕的 unit-level probe line）。
  建議先做這個 Option A+。只有在 cue 行沒辦法讓生成的屬性正確率提升時，才考慮 Option B，而且只送 kidney / organ 的
  vec16 單元 token，不送 grid。

## 方法細節（fold、probe）
- 各類 fold 來源：該類正式 OWL 堆疊的 train OOF 檔（integrated_best scores、region_units stack、osteopenia_v15、
  gallstones N_U、appendicitis RLQ、biliary BD5、fracture spine_ft labels.csv）。每一類所有有標籤的 train 病例都有官方 fold。
- 屬性的單元標籤、fold 和 probe 類型完全沿用同儕的 `report_gen/method4/improve/unit_probe.py`：程式是唯讀 import，
  run_task 從 logistic／MLP 中依 train OOF 選型。單元集合與同儕 OWL probe 相同，所以同儕的 val .939／.715、.929／.750
  在這裡能逐位重現。堆疊的 Pillar 輸入事前固定為 vec64+vec16。
- 分級屬性用該疾病的 fold，只在報告陽性、且有寫屬性的病例上做（`report_gen/targets` 的結構化欄位，不讀報告原文）。

## 規則
- train 一律 5-fold OOF，**每一類用該類正式 OWL 堆疊自己的 fold**（各類 fold 彼此不同，和肝脂肪的一致率約 20%＝隨機），所以 Pillar OOF 分數和 OWL OOF 分數屬於同一個切分，堆疊是 OOF-clean。val 只報告一次。test 從未讀取，也沒有 test 的 Pillar 特徵。
- Pillar probe：特徵標準化＋logistic regression；C ∈ {3e-4, 1e-3, 3e-3, 1e-2, 3e-2, 0.1}，以 train 內層 CV（外層每折用其餘 4 折做 leave-one-fold-out）選；val 用全 train 重訓（C 由 5-fold CV 選）。堆疊＝logit(OWL 機率) 與 Pillar OOF 分數的 LR（C=1）。
- 主要堆疊「OWL+P」＝OWL＋Pillar global＋Pillar 器官單元三個分數；另列 OWL＋global、OWL＋單元。
- CI：val AUROC 分層 bootstrap 2,000 次；Δ 為配對 bootstrap。單元層級（每腎、每節椎體）用病例叢集 bootstrap。
- 判定（事前固定）：Δ 的 95% CI 全部 > 0 →「Pillar 有幫助」；全部 < 0 →「變差」；其餘「無差異」。
