1. **I1 逐節監督**（lv）：椎體壓迫性 .909 → .920、輕度壓迫 .856 → .880（val；train 也一致：.915 → .927、.831 → .855），但肋骨／骨盆略降，整體不變（.828–.831）。lv03 最平衡。
2. **I2 困難陰性**：hn_b2 讓 Spearman .58 → .44、急性與臨床顯著提升（.864／.884），整體 .832；加權到 ×3 就變差。金屬／植入物（hn_m）沒有幫助。
3. **I3 年齡**：完整年齡配對加權（age_full）讓年齡相關性消失（Spearman −.09），但 AUROC 掉到 .801；開根號版與 pairwise 排序損失都沒有增益。它在集成裡貢獻「去年齡」的訊號。
4. **I4 FOV 降權**：沒有影響（±.002）。
5. **肋骨**：18 根單肋骨單元（r18）單獨 val .833／年齡配對 .814，但 train OOF 只有 .831（所以單獨不會被選上）；逐根監督（rl1）讓只有肋骨的骨折 .752 → .771–.777，但整體退步 .003–.008。
6. 進步主要來自**不同訓練目標的模型互補**（同一種模型多加 seed 在 10 seed 後就已飽和；hard label 3 seed .829 vs 10 seed .831）。
