# 骨折依部位給分（site-wise scoring）— 2026-11-06

規則：只用 train/val（標籤先依 split.csv 過濾 train/val 再解析）；所有選擇只依 train 5-fold CV（外層 folds 同 C3 stacker；site head／C3 stack 在每個外層 train 內重 fit，第二層 LR 用外層 train 內的 inner 5-fold OOF 訓練，無洩漏）；val 只報告；test 未讀取。
val 共同集 N=4941（骨折 553、陰性 4388）；train N=15053。群組人數：椎體壓迫性 290，肋骨 158，只有肋骨 108，骨盆/薦椎/髖 135，急性(含混合) 112，陳舊 336。
Bootstrap 2000 次；Δ 為配對 bootstrap。子群組 AUROC＝該群陽性 vs 全部陰性。

## 部位分數定義
- site head＝LR（不加權→機率校正）以「部位標籤」訓練：該部位骨折＝1、無骨折＝0、其他部位骨折排除。部位：椎體＝sites 含 vertebra；肋骨＝rib；骨盆＝pelvis/sacrum/hip_femur（與既有報告的子群組同源：labels_disease14_all.jsonl 的 fracture.detail.sites／vertebral_compression）。
- S1（單一分數）：椎體＝J_add、肋骨＝L 的 rib15 site logit、骨盆＝U_pel。
- S2（多輸入 site head）：椎體＝J_add＋L v15/v3 site＋L-Jadd v15/v3 site＋expI 椎體 site；肋骨＝L rib site＋L 單肋 instance max＋L-Jadd rib3 site＋expI 肋骨 site；骨盆＝U_pel＋U_org_pel＋U_org_out＋L 骨盆 site＋L-Jadd 骨盆 site＋expI 骨盆 site。（expI site＝greedy 骨骼群組 ['hn_b2', 'lv1', 'age_full', 'hn_m3', 'r18'] 的 site logit，train z 後平均）
- 合併：max＝校正後部位機率取最大；noisyor＝1−Π(1−p)；lse＝部位 logit 的 logsumexp；+any＝再加一個以整體標籤校正的 LR(C3 六成員) 作第 4 個分量；lr＝LR(三個部位 logit)；lrc3＝LR(三個部位 logit＋C3 stack)。
