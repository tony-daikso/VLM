## 結論與建議（需使用者決定，未執行）

1. 清理可能有幫助的地方：(a) 椎體成形術骨水泥、明確「壓迫變形」→ 改為陽性或排除；(b) 橫突／棘突／pars 骨折、FOV 外骨折、非骨折病灶 → 從陽性排除或另列。估計 train AUROC 上限 +.008～+.015，但這會**改變標籤定義**，必須在看 test 前鎖定，val 也要用同一套規則重算，不能只改 train。
2. 低成本做法（不改官方標籤）：訓練時把上述可疑例子降權或排除（只影響 train），評估仍用官方標籤。預期增益小（≤ +.005），因為主要的漏標（158 例報告完全沒提）沒有文字證據可以修正。
3. 最大的單一誤差來源仍是真正困難的陽性：無位移或癒合中的肋骨骨折、陳舊骨折，這正是 rib_straight 要處理的部分。
