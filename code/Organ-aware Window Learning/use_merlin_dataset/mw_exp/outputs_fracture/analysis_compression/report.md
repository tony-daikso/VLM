# 椎體壓迫性骨折為何卡在 0.90：錯誤分析（2026-11-05）

## 設定
- 目標：骨折 yes/probably_yes 且 `vertebral_compression == "yes"`；陰性：no/probably_no/not_mentioned；其他骨折排除。
- 模型分數：實驗 F 骨骼集成 `bone_ens.npz`（17 單元依部位 MIL，10 seed）。**分析一律用 train 5-fold OOF**：陽性 902、陰性 13,382，AUROC **.915**（val .906）。
- 固定門檻：train OOF 陰性 90% 特異度（logit ≥ 0.805）→ 敏感度 77.2%；偽陰性（FN）206 例、偽陽性（FP）1,338 例。
- 子群成本 =（子群占陽性或陰性的比例）×（其餘病例的 AUROC − 子群 AUROC），單位為 AUROC 點（0.01）。各子群會重疊，成本不能直接相加。
- 報告文字：LLM 擷取的 quotes 加上 Merlin 報告（`reports.json`），只取 train/val。椎節用 regex 解析（例如 T\d、L\d 與範圍寫法）。
- 逐節分數：重新訓練與實驗 B 相同的依部位 max 模型（ref，3 seed × 5 fold，CPU），保存椎體 head 在 T8–L5 每節的 OOF logit（`perunit_oof.npz`），train OOF AUROC .909。
- val 只做描述性比較，沒有用來調整任何東西。

## 結論摘要
**卡住的主因不是範圍或分割，而是「輕度壓迫」與「年齡/退化混淆」**：
1. 在 3 mm 下看不出來的**輕度楔形/輕度高度流失**陽性，加上**影像上像骨折的老年退化脊椎**陰性，兩者合計約佔 7–8 個 AUROC 點的差距。
2. 範圍與分割問題的影響小於 0.1 點。
3. 標籤雜訊大約只佔 1 點。

## 上限估計
- **乾淨子集**：排除可疑雜訊和只有終板變化的陽性 → .921；再排除輕度 → **.951**。另一種是兩邊都清：陽性排除雜訊與終板，陰性排除漏標、內固定與 not_mentioned → **.929**。
- **標籤雜訊公式**：假設陽性錯標率 a ≈ 2–5%、陰性中藏有的陽性 b ≈ 0.5–1%（依據：可疑陽性 5.4%＋只有終板 4.5% 約一半是錯的；具 TP 型局部訊號的 FP 佔陰性 0.8%）。在這個假設下：
  - 完美模型能觀察到的 AUROC 為 .97–.99。
  - 若模型對「真標籤」的 AUROC 是 .95，觀察值為 **.923–.939**；若是 .93，觀察值為 .904–.919。
- **判斷**：在現行標籤下，合理可達的範圍約為 train OOF **.925–.935**、val **.915–.93**。val 要穩定到 .93，必須同時：(1) 讓輕度組從 .83 提升到約 .89，以及 (2) 讓老年、退化陰性的 FPR 下降。只改特徵聚合或集成方式（實驗 E/F/G 的方向）不可能達到。
