# 陳舊骨折：錯誤分析與年齡影響（train OOF）

- 分數：`final_F1/groups/bone_ens`（train OOF，整體 AUROC .835）；另以 `final_G/ens_all`、E3_late 10 seeds 平均複核，結果幾乎相同。
- 族群定義：
  - 陽性 = fracture yes / probably_yes；陰性 = no / probably_no / not_mentioned（unclear 排除）。
  - 陳舊 = acute "no"；急性(含混合) = yes / mixed；未註明 = not_stated。
- train 人數：陰性 13,344；陳舊 962；急性(含混合) 344；未註明 364。
- 所有分析都在 train OOF 上做；val 只做描述，沒有拿來調任何東西；test 完全沒讀。
- 程式與 CSV 放在 A6000 `outputs_fracture/analysis_old/`。

## 1. 年齡的預測力（核心結果）

| 族群 | n | 陽性平均年齡 | 只用年齡 AUROC | 模型 AUROC | 模型 年齡配對(±2y) | 模型 − 年齡 |
|---|---|---|---|---|---|---|
| 全部骨折 | 1670 | 64.8 | .678 | .835 | .811 | +.157 |
| **陳舊** | 962 | 67.2 | **.718** | .847 | .808 | **+.129** |
| **急性(含混合)** | 344 | 61.2 | **.619** | .828 | .825 | **+.209** |
| 未註明 | 364 | 61.7 | .629 | .811 | .804 | +.182 |

（陰性平均年齡 52.8 歲。只用年齡、再做年齡配對的 AUROC 是 .503–.510，代表配對有效。）

- **分數與年齡高度相關**：陰性樣本中 Spearman(分數, 年齡) = .59（ens_all .59、E3_late .56）。
- **Bootstrap（300 次）**：
  - 未經年齡調整的模型 AUROC，陳舊 − 急性 = +.019 [−.005, +.049]。
  - 「模型 − 年齡」差距，陳舊 − 急性 = **−.081 [−.114, −.046]**。
  - 也就是說：模型比單用年齡多出的部分，在陳舊骨折上明顯縮小。
- **年齡分層後的模型 AUROC**：
  - <50 歲：陳舊 .813 / 急性 .799
  - 50–65 歲：.825 / .837
  - 65–75 歲：.797 / .813
  - \>75 歲：**.805 / .866**
- **把年齡加進模型沒有用**：bone_ens 加上年齡（及年齡²、椎體 HU）做 5-fold LR，整體只從 .835 變成 .836，陳舊 .847 不變。年齡資訊已經被模型吸收了。
- **val（只做描述）**：
  - 模型：陳舊 .826 / 急性 .845；只用年齡：.667 / .698（val 的急性組比較老）。
  - val 急性只有 112 例，信賴區間很寬；train 上陳舊與急性的順序和 val 相反。
  - 比較穩定的差異是年齡配對後的 AUROC：陳舊 .808 vs 急性 .825。
- **結論**：陳舊骨折的原始 AUROC 約有 .04 靠「病人比較老」撐起來。去掉年齡之後陳舊才比急性弱，而且主要弱在 \>75 歲的族群。

- **最難的子型**：用「healed / old」描述的（以肋骨為主），年齡配對後只剩 .72–.73。
- **容易的子型**：用「變形 / 穩定 / 慢性」描述的，大多是壓迫性骨折。
- **骨水泥**：在陽性中容易被抓到；但陰性中也有 13 例做過 vertebroplasty，它們的分數偏高（相對其他陰性 AUROC .86）。人數太少，影響可以忽略。
- **金屬植入物**：陰性中有 7.3%，分數偏高（AUROC .72），在偽陽性中富集 2.9 倍。

## 4. 嚴重度與可見度（壓迫性骨折的幾何指標）

|---|---|---|---|
| 陳舊 | .263 | .556 | **22.6%** |
| 急性 | .280 | .636 | 26.6% |
| 陰性 | .222 | .727 | 39.9% |

**依幾何分箱的模型 AUROC**：

| max_height_loss | 陳舊 | 急性 |
|---|---|---|
| <0.15 | .887（n=117） | .867（n=41） |
| 0.15–0.25 | .930 | .969 |

- 幾何特徵本身很弱：單獨拿 max_height_loss 做預測，陳舊 .557、急性 .551。
- 原因是高度量化成 3 mm 的倍數，雜訊很大。
- 結論：壓迫性骨折不是陳舊組的主要失分來源。

## 5. 標註一致性

- **陰性中疑似漏標很少**：報告提到陳舊骨折、壓迫變形或 vertebroplasty（且沒被否定）的只有 28 / 13,344（0.21%）。
  - 其中 13 例是 vertebroplasty，約 2 例是「chronic rib deformities」。
  - 真正可能漏標的約 15–20 例（約 0.13%）。
- **LLM 標註非常一致**：陰性報告中，連同被否定的句子一起算，出現「old/healed fracture」或「compression fracture」的也只有 8 例。
- **排除疑似漏標的影響可忽略**：整體 .835→.836，陳舊 .847→.848。
- **陽性端**：陳舊中 probably_yes 佔 1.6%，語氣保留佔 5.4%。
- **標註雜訊上限**：設陽性錯標率 a=5.4%、陰性錯標率 b=0.2%，AUROC 上限約 .97，不構成限制。
- **無法量化的部分**：放射科醫師根本沒寫進報告的陳舊骨折（尤其是已癒合的肋骨）。偽陽性中高齡與骨質疏鬆的富集和這種情況相符，但要看影像才能確認。

## 7. 評估定義（不重訓，只換定義）

| 定義 | 陽性數 | 模型 | 只用年齡 | 年齡配對 |
|---|---|---|---|---|
| 任何骨折（目前） | 1670 | .835 | .678 | .811 |
| 僅急性 vs 陰性 | 344 | .828 | .619 | .825 |
| 急性 vs 其他全部（陳舊算陰性） | 344 | **.799** | .603 | .797 |
| 臨床顯著（急性 ∪ 中重度壓迫 ∪ 非術後髖/股骨） | 508 | **.868** | .673 | .859 |
| 排除單純陳舊肋骨 | 1429 | .847 | .676 | .830 |

- 把陳舊算成陰性，AUROC 反而下降。表示模型學到的是「骨折的型態」，而不是「急不急性」。這和先前分開急性/陳舊 head 效果較差的結果一致。
- 「臨床顯著」定義的 AUROC 最高，受年齡影響也最小，建議並列為次要評估指標。

## 失分來源排序（估計對陳舊 AUROC 的損失）

1. **陳舊肋骨**（.768）：提升到急性肋骨水準（.831）→ 陳舊 +.016，整體 +.009。
2. **年齡混淆 / 高齡陰性**：原始 AUROC 不受影響，但年齡配對後少約 .04；\>75 歲族群比急性低 .06。
3. **FOV / 遮罩看不到**（7.9%，.73）：補到 .85 → 陳舊約 +.009。
4. **骨盆/薦椎陳舊**（.782）：約 +.005。
5. **幾何細微的壓迫性骨折**：約 +.005。
6. **語氣不確定的陽性**：約 +.004。
7. **陰性漏標、骨水泥/金屬干擾**：<.001。

## 估計上限

- 肋骨提升到急性水準、骨盆提升到 .837：陳舊 train OOF 約 .868（+.02），對應 val 約 .845–.85，大致與急性持平。
- 再加上 FOV 修正：約 .875。
- 標註雜訊的上限約 .97，不構成限制。

## 前三項修正

1. **陳舊肋骨專用路徑**
   - 做法：高解析度肋骨 crop，使用骨窗/皮質窗，加入骨痂與皮質不連續特徵；用報告解析出的肋骨序號做 rib-level MIL 監督。
   - 預期：陳舊 +.010–.016，整體 +.005–.009。
   - 成本：中高。rib18 目前的 G ensemble 只帶來 +.0003，只改聚合方式不夠。
2. **FOV / 遮罩感知的訓練與評估**
   - 做法：報告指的部位不在影像或遮罩內的陽性（陳舊中 7.9%）降權或改用軟標籤；另外報告「FOV 可見子集」的 AUROC。
   - 預期：模型 +.003–.005，可見子集指標約 +.01。
   - 成本：低。
3. **高齡困難負樣本 / 年齡配對抽樣**
   - 做法：在凍結特徵上重訓 head，對 ≥75 歲且有骨質疏鬆、側彎、退化、金屬的陰性加權，或使用年齡配對的 pairwise loss。
   - 預期：年齡配對 AUROC +.01–.02，原始 AUROC +.003–.008。
   - 成本：低到中。直接把年齡當特徵只有 +.001。

**附帶建議**：並列「臨床顯著」AUROC（.868）作為次要指標；不要把陳舊骨折當陰性。
