- 依 train CV 選出 rp_both_aa：train CV .8871（spine15_add .8824、with_rib .8788），val **.882 [.866, .898]**，Δ vs .878（with_rib）**+.005 [+.001, +.009]**、Δ vs .862 **+.021 [+.014, +.028]**；年齡配對 .872（vs with_rib +.007 [+.002, +.013]）。
