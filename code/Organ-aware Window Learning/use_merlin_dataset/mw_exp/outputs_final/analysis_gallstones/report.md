# 膽結石：錯誤分析（train 5-fold OOF）

日期：2026-11-05｜主機：A6000 `~/Desktop/Tony/VLM/OWL/mw_exp/outputs_final/analysis_gallstones/`｜**test 未讀取、未評分**

## 0. 方法
- 分析資料：train（陽性 1,343／陰性 13,770，排除 unclear）。用 probe.py 的設定跑 5-fold OOF：膽囊單元、標準化、class-balanced BCE、lr 1e-3／wd 1e-4（expB 選出的超參數）。early stopping 改用 train fold 內 15% 的 holdout，不看 val。聯合訓練的 finding 限於同屬膽囊單元的 膽結石＋膽囊切除術後（兩者共用 E3_late gate）。每種設定 2 個 seed 取平均。
- 重現檢查（val，只描述）：本流程 E0 0.755、E3_late 0.773；expB 原始結果是 0.767／0.783。差距來自 early stopping 改用 train holdout，不影響以下結論。
- HU 特徵：從 3 mm prep 的 HU 與 TS 膽囊遮罩計算，涵蓋 train＋val 全部 20,364 例。A6000 跑 10,518 例，CT-rate CPU 跑 9,846 例。
- 文字特徵：只用 train／val 的報告，取含膽囊、膽道相關字詞的句子做關鍵字比對。Qwen 標註的 `calcified` 欄位也一併使用。
- 堆疊：與 OOF 共用同一組 fold，做 logistic regression（C=0.3，class-balanced）。

## 1. 總覽（train OOF AUROC）
| 設定 | AUROC |
|---|---|
| E0（baseline） | 0.772 |
| E3_late | 0.782 |
| E1 soft_tissue / liver / narrow_abd / bone | 0.774 / 0.761 / 0.765 / **0.779** |
| 只用 HU 特徵（LR） | 0.794 |
| 各 window logit 堆疊（LR） | 0.800 |
| **E3_late + HU 特徵堆疊** | **0.827（+0.045）** |
| E3_late + HU + 年齡／性別 | 0.838 |
| 各 window logit + HU | 0.832 |

val（描述用，不調參）：E3_late 0.773 → 以 train OOF 訓練的堆疊模型 **0.810（+0.037）**。

在 90% 特異度下，敏感度從 E3_late 的 54.3% 提升到堆疊後的 59.7%。

## 2. 原因排序（依估計的 AUROC 損失）
| # | 原因 | 證據（train OOF） | 估計損失 |
|---|---|---|---|
| 1 | **結石在 CT 上不可見或不明顯**（等密度、膽固醇結石、小結石） | 38% 的陽性在膽囊內沒有 ≥2 個相連、>100 HU 的體素。這組 AUROC 只有 **0.673**；可見組為 0.850。報告寫「tiny/small」的 0.739、「layering」的 0.755、「non-calcified」的 0.724。這組加 HU 堆疊也沒有幫助（0.672）。 | ≈0.07（大多無法從 3 mm 影像救回） |
| 2 | **mean pooling 稀釋了高密度結石的訊號** | 單一特徵「膽囊內最大 HU」的 AUROC 就有 **0.762**，和整個 embedding 相當。膽囊內 >200 HU 的情形：陽性 23.6%、陰性 1.1%。可見組 AUROC 從 E3 的 0.851 升到堆疊後的 **0.925**。 | ≈0.045（加入 HU 特徵堆疊即可救回） |
| 3 | **膽囊遮罩缺失**，以及**膽囊切除術後陰性被當成「器官不存在」** | 8.9% 的陽性膽囊遮罩 <100 vox，這組 AUROC 只有 **0.572**（陰性中為 6.4%）。器官缺失時 logit 是常數：遮罩缺失的陽性平均 −0.98，膽囊切除術後陰性 −1.00，兩者幾乎一樣，模型分不開。陽性 vs 只有膽囊切除術後陰性的 AUROC 為 0.770，比 vs 有膽囊陰性的 0.786 還低。也就是說，膽囊切除術後陰性**不是簡單的陰性**。 | ≈0.02 |
| 4 | 年齡捷徑 | 年齡單獨的 AUROC 0.649；同一年齡層內 AUROC 降到 0.755–0.780（≥60 歲最低） | 部分分數來自年齡，不是真正的影像訊號 |
| 5 | 標籤雜訊 | probably_yes 佔陽性 3.9%（AUROC 0.711）；同時標為膽囊切除術後的矛盾例 9 例。可疑陽性共 5.1%，拿掉後 AUROC 只從 0.782 升到 0.785。 | ≈0.003（小） |
| 6 | 顯影相位 | 門脈相 0.787、未打顯影劑 0.811（n=82）、arterial_late 0.63（n=26，太少）。陰性中 >100 HU 體素的比例在未打顯影劑與門脈相都是 35%，所以不是顯影劑造成。 | 可忽略 |
| 7 | 總膽管結石混淆 | 只佔陽性 3.6%，AUROC 0.847，不是問題 | 可忽略 |

補充：
- 膽囊大小：陽性的膽囊遮罩中位數 1,243 vox，陰性 973 vox。最大四分位的 AUROC 最低（0.763），可能和膽囊擴張（hydrops）有關。
- 膽管擴張和膽結石幾乎無關（以膽管擴張標籤預測膽結石的 AUROC 為 0.52）。

## 3. 90% 特異度下的錯誤分類（E3_late OOF；FN 614、FP 1,377）
**FN**（括號內為該類在全部陽性中的比例）
- F 非高密度（等密度或小結石）：30.1%（22.2%）
- G 高密度、可見，但模型仍漏掉：29.5%（44.5%）→ 加入 HU 特徵後可救回一部分
- D 報告用語不確定（probably、possible 等）：19.7%（22.6%）
- B 膽囊遮罩缺失或過小：**18.6%（8.5%，約 2.2 倍）**
- A 標註矛盾／E 只有膽泥／C 總膽管結石：合計約 2%

**FP**（括號內為該類在全部陰性中的比例）
- 膽囊內有 >100 HU 的塊狀高密度：41.2%（26.2%）。成因可能是部分容積效應、遮罩滲到鄰近強化組織或膽囊壁，也有少數可能是漏標。陰性中 >200 HU 只佔 1.1%，這群最可能是漏標。
- 膽囊擴張／發炎：6.2%（2.0%）
- 合併膽管擴張：5.0%（2.7%）
- 報告提到膽泥：1.4%
- 其他：46.3%

## 4. 上限估計
- 可見結石（62%）的 AUROC 若做到 0.93–0.97，不可見結石（38%）的 AUROC 維持約 0.67–0.72，混合後約 **0.85–0.87**。這是以凍結 encoder、3 mm 影像為前提的實際上限。
- 標籤清理的效益只有約 +0.003，瓶頸不在標籤。

## 5. 建議修正（前三名）
1. **加入膽囊 HU 特徵，做 late stacking**（膽囊內最大 HU、>130／>200 HU 體素數、>60 HU 體素數、p99、遮罩體積）。或在 embedding 加上 max pooling 或高 HU 體素比例的通道。
   - 預期增益：train OOF **+0.045**（0.782 → 0.827），val 描述 +0.037。
   - 成本：低。特徵已算好，test 只需在鎖定設定後跑約 10 分鐘 CPU。
2. **處理膽囊缺失**：把膽囊切除術後 head 的分數（AUROC 0.956）當成特徵或 gate；膽囊遮罩 <100 vox 時，改用膽囊窩的 ROI crop 做 fallback，或用 TS 1.5 mm 完整模型重新分割膽囊。
   - 預期增益：約 +0.01～0.02。
   - 成本：中。需要重新抽取約 1,500 例 train／val 的 embedding。
3. **膽囊高解析 crop（1.5 mm 或原始解析度）＋ 結石用的 window（例如 L130／W300，或高 HU 通道；目前單一 window 中 bone 最好）＋ finetune**，目標是小結石與等密度結石。
   - 預期增益：約 +0.01～0.03（不確定性高）。
   - 成本：高，需要 GPU 重新抽取或 finetune。

不建議優先做：標籤清理（+0.003）、依顯影相位分組（沒有差異）。另外，加年齡／性別雖然 +0.011，但屬於捷徑，不應計入。
