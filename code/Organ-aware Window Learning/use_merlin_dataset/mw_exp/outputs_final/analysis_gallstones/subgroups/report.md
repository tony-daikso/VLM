# 膽結石子群分析（GS1-V4，2026-11-05）

**目的**：目前最佳膽結石模型（GS1 **V4** 堆疊模型）對「不同種類」膽結石的偵測能力。只做分層，不改標籤定義（標籤問題見 LABEL_DECISIONS_PENDING.md）。

**資料與規則**
- 只用 train + val；讀任何標籤/報告前先依 split 過濾；**未讀取、未評分 test**。
- 主分析：train 5-fold OOF（陽性 1343 / 陰性 13770）；次要：val 描述性（陽性 465 / 陰性 4524）。
- 每個子群 = 「該子群陽性」 vs 「**全部**陰性」。AUROC：E3_late / quickwins / V4。
- 漏診率：V4 在 train OOF 陰性 90% 特異度的閾值（logit −2.034；val 沿用同一 train 閾值）下，子群陽性中被判陰的比例；「佔 V4 全部 FN」= 該子群 FN / 全部 FN（train 455 例，val 159 例）。
- 95% CI：子群陽性 ≥ 30 才算，1000 次 bootstrap（陽性與陰性分別重抽），只給 V4。
- 子群陽性數 < 30 的數字僅供參考。

## 子群定義（regex / 規則）
文字來源 = 報告中與膽囊/膽道有關的句子（含 gallbladder、cholelith、gallstone、sludge、cholecyst、biliary、cystic duct、CBD 等，或含 stone/calculus 但**排除**腎/輸尿管/膀胱/闌尾等句子）＋標籤 quotes。陽性詞若前方同一子句（最多 150 字元，以 `:` `;` but/however/with/which 切子句）出現 no / without / not / negative for / absence of / free of / resolved，視為否定。

| 軸 | 規則 |
|---|---|
| 1 大小 | 結石句中的 mm/cm（0.5–60 mm，排除含 CBD/膽管/腎等字的句子）取最大值：<5 mm 微小/小、5–10 mm 中、≥10 mm 大；無數值時，`tiny/punctate/small/minute/millimetric/subcentimeter + (0–3 字) + stone/gallstone/calculus/hyperdensity/focus` 或 microlith → 微小/小；`large/bulky/huge/giant/dominant + stone` 或 `filled/packed with stones` → 大；否則「未記載」。 |
| 2 數目 | 多顆：`multiple/numerous/several/innumerable/many/few/two/three/at least N/數字 + stones`，或複數 stones/gallstones/calculi；單顆：`single/solitary/a/an + gallstone/stone/calculus`（單數）；只寫 cholelithiasis → 未記載。 |
| 3a 鈣化(報告) | 非鈣化：標籤 detail.calcified = no，或 non-calcified/isodense/faint/subtle/low density/hypodense stone/cholesterol/radiolucent/「CT 上看不清楚、超音波可見」；鈣化：detail.calcified = yes，或 calcif/radiopaque/hyperdense/high density/lamellated；否則未記載。 |
| 3b 影像高密度(3mm) | 客觀影像軸：膽囊遮罩 ≥100 voxel 且 >100 HU 連通塊 ≥2 voxel（gb_maxblob100 ≥ 2）→ 可見；遮罩 <100 voxel → 遮罩缺失/過小。 |
| 4 位置/型態（可重疊） | 頸部：neck/impacted/lodged/cystic duct/infundibulum/Hartmann（限結石句）；分層：layering/dependent；底部：fundus/fundal；充滿/收縮：filling/filled/packed gallbladder、gallbladder contracted/collapsed/decompressed；瓷器：porcelain/wall calcification。 |
| 5 合併症 | 膽囊炎徵象：cholecystitis/pericholecystic/壁增厚/hyperemia/mucosal enhancement/emphysematous/gangrenous（未否定）；膽管：報告 choledocholithiasis/CBD stone/Mirizzi **或** biliary_ductal_dilation 標籤陽性。互斥分組：兩者皆有 / 只有膽囊炎徵象 / 只有膽管 / 單純。另列「膽囊擴張(distended/hydrops)」為重疊軸（未計入膽囊炎徵象）。 |
| 6 確定度 | 標籤 probably_yes，或 quotes 含 possible/likely/probable/suspected/cannot exclude/may represent/equivocal/versus → 可能/疑似；否則確定。 |
| 7 膽泥 | sludge/tumefactive/vicarious excretion（未否定）且無結石字 → 僅膽泥；兩者皆有 → 膽泥+結石。 |
| 8 膽囊遮罩 | gb_vox ≥100 存在；<100 缺失/過小。 |

## 僅膽泥（目前一律標為陰性）
- 目前標籤：「僅膽泥」train 164 例全部為陰性（no 39 / probably_no 113 / not_mentioned 12），val 59 例同樣全為陰性；沒有任何僅膽泥被標為陽性。「膽泥+結石」大多為陽性（train 55/61）。
- V4 在 90% 特異度閾值下把**僅膽泥陰性**判為陽性的比例：train 32.3%、val 35.6%，約為其他陰性（9.7%）的 3 倍 → 若標籤改為「膽泥算陽性」，這群會從 FP 變 TP；目前算 FP。是否改標籤待使用者決定。
- 對照：影像可見高密度的陰性 FP 20.7%（顯影劑/壁鈣化/鄰近骨骼等），影像無高密度陰性 8.0%，遮罩缺失陰性 2.9%。

## 重點結論
1. **最強的決定因素是「3 mm 影像上看不看得到高密度」，不是報告的描述。** 影像可見 >100 HU 的陽性 AUROC 0.931（漏診 18%）；影像無高密度 0.782（漏診 56%），一個子群就佔全部 FN 的 50%；膽囊遮罩缺失/過小 0.709（漏診 66%，佔 FN 17%）。後兩者合計佔陽性 39%，卻佔 FN 68%。val 完全重現（0.926 / 0.789 / 0.702）。
2. **報告寫「鈣化」不代表 3 mm 影像看得到。** 報告鈣化但影像無高密度（train 81 例）V4 只有 0.804、漏診 51%；報告與影像都說高密度則 0.935。報告「非鈣化/等密度/模糊」0.818（漏診 48%）。75% 陽性報告沒寫密度，所以影像軸比報告軸更有用。
3. **大小：微小/小結石最難**（0.784，漏診 52%，val 0.759），大結石 0.923、中 0.968（n 小）。其他偏難型態：充滿膽囊/膽囊收縮含石 0.798（漏診 47%）、分層/重力依賴 0.845（漏診 46%）、報告為可能/疑似 0.799（漏診 52%）、膽泥+結石 0.840。單顆 vs 多顆幾乎無差（0.865 vs 0.860）。
4. **臨床重要的合併症子群反而偵測得好**：合併膽囊炎徵象 0.926–0.928（漏診 19–21%）、頸部/嵌頓/膽囊管結石 0.914（漏診 24%）、報告提及膽管結石 0.926（n=37）。最弱的是「合併膽管擴張/膽管結石（無膽囊炎徵象）」0.848、漏診 40%（val 0.873）。
5. **V4 相對 E3_late 的進步主要在「看得到」和「遮罩缺失」**：可見 0.854→0.931、遮罩缺失 0.572→0.709（quickwins 在此僅 0.510）；影像無高密度只從 0.701→0.782，仍是主要缺口（小結石、非鈣化、收縮膽囊多落在這裡）。

## 注意事項
- 子群由報告 regex 推得，會有誤分（例：「大結石 + 另一顆小結石」被歸為單顆；未寫明的特徵全部落在「未記載」）；抽查約 60 例後已修正否定詞與腎結石句誤抓。
- 合併膽囊炎/膽管擴張子群偏易，部分可能因為模型同時學到膽囊/膽道的整體異常（非結石本身），不代表結石本身更好認。
- val 子群多數 n<50，僅作描述；test 未使用。
