## 0. 方法
- 資料：train 陽性 407（yes 340＋probably_yes 67）／陰性 14,790（no＋probably_no＋not_mentioned），排除 unclear 112 例。val 陽性 118，只做描述。先用 `split.csv` 以 study_id 過濾 train／val，才解析標籤或報告。
- OOF：沿用 probe.py 的設定。單元依 `finding_organ_map.yaml` 用大腸（colon）；標準化、class-balanced BCE、lr 1e-3／wd 1e-4。early stopping 改用 train fold 內 15% 的 holdout。E0、E3_late 各跑 3 個 seed，其餘設定 1 個 seed。另外加跑大腸＋小腸（E3_late_colon_sb）與只用小腸。
- 重現檢查（val，只描述）：本流程 E0 0.839、E3_late 0.859；expB 原始數字是 0.839／0.853。
- **TotalSegmentator 沒有闌尾或盲腸類別**。已查過已安裝版本的全部 task：`total` 只有 colon／small_bowel；名稱含 append 的 task 只有 `appendicular_bones`（四肢骨）與心耳。因此用 HU 特徵當代理：
  - **盲腸代理**：大腸遮罩中位於脊椎中線右側 ≥30 mm、最靠尾端 45 mm 的體素。
  - **ROI**：盲腸代理周圍 ≤15 mm 與 ≤30 mm、TS 單元以外的體內體素。
  - **特徵**：脂肪 HU 中位數／p75、浸潤比例（−70～20 HU）、液體比例（0～30 HU）、軟組織比例、小型高密度灶（>200 HU、≤15 vox，作為糞石代理）。
  - **對照**：左下腹同一高度的相同特徵（右減左），以及全身脂肪 HU（RLQ 減全身）。
  - 用 3 mm prep 計算 train＋val 共 20,364 例：A6000 10,518 例、CT-rate 9,846 例，皆 nice 19、CPU。盲腸代理定位失敗只有 0.8%。
- 堆疊：與 OOF 共用 fold，LR（C=0.1、class-balanced）。CI 一律用分層 bootstrap 1,000 次；差值 CI 用配對 bootstrap。

## 4. 上限估計
- **標籤清理**後 E3_late 0.838，E3＋HU 0.865；全部方法合併（大腸＋小腸＋HU）約 **0.87–0.88（train OOF）**。val 比 train OOF 高約 0.03–0.05，因為 val 是用全部 train 擬合，訓練量較大。所以凍結 encoder、3 mm、沒有闌尾遮罩的前提下，實際上限約 **val 0.89–0.91**。
- 年齡配對 AUROC 目前最好是 0.793。要超過約 0.85，需要真正看到闌尾本身（管徑、壁厚、糞石），也就是更高解析度的 RLQ crop 加上 finetune。
- 在 118 個 val 陽性下，AUROC 的 95% CI 寬度約 ±0.033，小於 0.02 的差異都看不出來。

## 5. 建議修正（前三名）
1. **把 RLQ 局部 HU 特徵（浸潤、液體、脂肪 HU，右減左／減全身）以 late stacking 疊在 E3_late 上**，並同時用大腸＋小腸單元。
   - 預期增益：train OOF +0.046（0.808 → 0.855），年齡配對 +0.058，val 描述 +0.027（0.859 → 0.885）。
   - 成本：**低**。特徵已算好，test 只要在鎖定設定後跑 CPU 約 1 小時。修改 `finding_organ_map`：闌尾炎改為 [colon, small_bowel]。
2. **建立 RLQ／盲腸 crop 單元，重新抽 embedding**：以盲腸代理（或 TS 的 iliopsoas_right／hip_right 當定位點）為中心，取 1.5 mm、約 96³ 的 crop，送進凍結 encoder，pooling 加上 max 與浸潤比例通道。
   - 預期增益：在第 1 項之上約 +0.01～0.03（不確定性中等），主要改善早期與管徑小的病例。
   - 成本：中。需要對 train＋val＋test 約 2.5 萬例重新做 crop 與 encoder forward（GPU 約數小時）。TS 沒有闌尾 task，沒有現成遮罩可用。
3. **修正標籤定義並加入去年齡訓練**：
   - 把「治療中、追蹤、術後」與 probably_yes 標成 unclear 或另外做一個 head。只拿掉這些可疑標籤，train OOF 就從 0.808 升到 0.838。
   - 訓練時用 trap，或在年輕族群（<45 歲）內做困難陰性加權，讓明確寫正常闌尾的陰性更有份量。
   - 預期增益：帳面約 +0.03（屬於評估定義的改變，報告時要分開列）；年齡配對 AUROC 約 +0.01～0.02。
   - 成本：低（只需重跑 probe）。

另外，finetune encoder（RLQ crop 加多 window 輸入）可能把年齡配對 AUROC 推到 0.85 以上，但只有 118 個 val 陽性，難以驗證，成本也高，所以排在上述三項之後。

不建議優先做：只換 window（liver／narrow 反而更差）、在堆疊中加入年齡（沒有增益，而且是捷徑）、依顯影相位分組。
