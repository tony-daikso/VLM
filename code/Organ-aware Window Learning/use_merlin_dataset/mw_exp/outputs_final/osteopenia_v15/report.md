# 骨質減少 × 1.5 mm 逐節椎體 embedding（Exp J）

## 結論
- **有新的正式最佳**：依 train OOF 選出 **「5 個 window logit＋1.5 mm 逐節 embedding head（LR）」**。
  - train OOF：.904 → **.908**
  - val：.884 → **.890** [.870, .908]，**Δ +.006 [+.001, +.013]**，CI 不跨 0
- **年齡配對 AUROC 也提升**：.784 → .798（Δ CI [+.004, +.027]）；年齡×性別層內 .776 → .795。所以增益不是來自年齡。
  - 不過陰性中分數與年齡的 Spearman 從 .729 升到 .749，模型仍高度依賴與年齡相關的骨密度訊號。
- **單用 1.5 mm embedding 就追上 3 mm 的 5 window 堆疊**：4 節串接的 LR，train OOF .905（3 mm 堆疊 .904）、val .888、年齡配對 .798。
- **骨小樑 HU 沒有幫助**：1.5 mm 核心 HU 和 3 mm HU，加進任何組合 OOF 都 −.002。這和錯誤分析一致：embedding 已經帶有 HU 資訊。
- 增益（+.006）符合錯誤分析估計的上限 .91–.92，受標籤限制。要再往上，需先決定標籤定義（待使用者決定）。

## 方法
- **資料**：train 15,256 例（陽性 712）、val 5,034 例（陽性 235），已排除 unclear。標籤只讀 `analysis_osteopenia/labels_trval.csv`（只有 train／val），先依 split 過濾。
- **1.5 mm embedding**：來源 `outputs_vert15/merged_final/emb15`，取 L1–L4，3 個 window（baseline／soft_tissue／bone）× 448 維。
  - pooling：mean，另外測 max。
  - 缺 1 例（train 陰性 AC423d284），以中位數補值。
  - 以 train 中出現的椎節做標準化。
- **fold 與選模**：fold 和 `analysis_osteopenia` 相同（`oof_train.csv` 的 fold 欄）。模型與超參數只依 train OOF 挑選；val 只套用一次做報告。
- **embedding 模型**
  - LR（class-balanced），C 網格 1e-5～1e-2。輸入分四種：L1–L4 平均（3 個 window）、L1–L4 平均（只用 baseline）、平均＋max pooling、4 節串接。
  - MIL（torch）：每節一個線性 logit，跨節取 mean 或 max；另有 gated attention。class-balanced BCE、Adam lr 1e-3、wd {1e-4, 1e-2}，early stopping 用 train 內 15% holdout，2 個 seed。
- **堆疊**：用 `integrated_best/ib_core.select_and_fit`，候選 LR C .1／.3／1；含 HU 的組合另加 1 個 GBM。可組合的成分：
  - 1.5 mm head（OOF 最佳的 4 節串接）
  - 3 mm lumbar_spine 的 E3_late，或 5 個 window logit
  - integrated_best 的 stack 分數
  - HU 特徵
- **HU 特徵**
  - 1.5 mm 骨小樑核心 HU：geom15 的 `hu_body`，即 seg15 椎體在正中矢狀面侵蝕 2 px 後的 HU 中位數，涵蓋 99.7%。這已經是用 1.5 mm mask 算出的核心 HU，所以不需要再讀 seg15。
  - 3 mm 椎體 HU：L1–L4 的 `hu_med`。
- **指標**
  - AUROC＋分層 bootstrap 95% CI（2,000 次）。
  - Δ：相對 integrated_best val（.884）的成對 bootstrap。
  - 年齡配對 AUROC：10 歲分層，依配對數加權；Δ 用 500 次 bootstrap。
  - 年齡×性別層內 AUROC：依配對數加權。
  - Spearman：只算陰性。
  - **年齡、性別從未作為模型輸入。**

## 解讀
1. **1.5 mm 帶來 3 mm 沒有的資訊**。單用 1.5 mm 就和 3 mm 的 5 個 window 堆疊同級（OOF .905 vs .904）。兩者合併後，OOF +.004、val +.006、年齡配對 +.014，可見兩者互補，而且互補的部分不是年齡。
2. **跨節聚合**：4 節串接（各節有自己的權重）最好；平均和 max-MIL 次之；attention 和 mean-MIL 最差。L1–L4 各節的資訊不完全相同，但只有 712 個陽性，attention 學不起來。
3. **HU 沒有用**。1.5 mm 核心 HU 單獨只有 .845，加進任何組合都 −.002。結論和錯誤分析相同：embedding 已經能解碼 HU。
4. **上限**。.908 已接近錯誤分析估計的上限 .91–.92。剩下的差距主要來自報告漏寫和標籤定義，要等使用者決定是否重新定義骨質減少的標籤。

## 注意
- 1.5 mm head 的 C 和堆疊都在同一組 fold 的 OOF 上挑選，所以 train OOF 會略微樂觀。val 只套用一次，不受影響。
- 部署到 test 前，需要先對 test 跑 Exp J 的 1.5 mm 分割與 embedding；目前 emb15 只有 train／val。要等使用者鎖定設定後才跑。
- 「integrated_best＋1.5 mm」（OOF .9078）和正式最佳（.9080）幾乎相同，val 也一樣（.891 vs .890），兩者可以互換。正式列照規則取 OOF 最高者。
