# 膽囊切除術後：錯誤分析（train 5-fold OOF）

日期：2026-11-05｜主機：A6000 `~/Desktop/Tony/VLM/OWL/mw_exp/outputs_final/analysis_absent_gb/`｜**test 未讀取、未評分**

## 0. 方法
- 資料：train 陽性 3,381／陰性 11,889（排除 unclear 39 例）；val 陽性 1,058（只描述，不調參）。讀任何標籤或報告之前，先依 split 過濾 id。
- OOF：沿用 `analysis_gallstones/scripts/gs_oof.py` 的設定（probe.py 設定：膽囊單元、標準化、class-balanced BCE、lr 1e-3／wd 1e-4、與膽結石共同訓練、共用 E3_late gate）。early stopping 改用 train fold 內 15% 的 holdout，不看 val。每種設定取 2 個 seed 平均。在 Mac 上用 train／val 的膽囊 embedding 切片執行（nice 19、4 threads），跑完後已刪除切片。
- 重現檢查（val，只描述）：本流程 E0 0.949、E3_late 0.950；expB 原始結果是 0.955／0.956。差距來自 early stopping 改用 train holdout，以及只用膽囊單元。
- 影像特徵（train＋val 全部 20,364 例；A6000 算 10,518 例、CT-rate 算 9,846 例，只用 CPU）：從 TS --fast 3 mm 的 117 類遮罩加上 prep HU 計算。
  - **膽囊遮罩**：體積、連通塊數、HU 中位數、液體／脂肪／空氣比例、與肝和腸道的接觸比例。
  - **膽囊窩 ROI**：以肝臟 bounding box 的相對位置（z 0.336、y 0.700、x 0.661，由 400 例 train 陰性的膽囊重心中位數估出）為中心，取半徑 30／50 mm 的球。排除骨骼（外擴 2 voxel）、血管、腎、腸道（外擴 1 voxel）。在 ROI 內計算 >500／800／1200 HU 的體素數（手術夾）與內容物比例。
  - **肝周 shell**：肝臟外 9 mm 內，>800／1200 HU 的體素數。
  - **全身金屬**：骨骼外 >1500 HU 的體素數。
- 堆疊：與 OOF 共用同一組 fold，比較 LR（C=0.3）與 HistGradientBoosting；val 只描述。

## 2. 原因排序（依估計的 AUROC 損失；E3_late 總損失 0.049）
| # | 原因 | 證據（train OOF） | 估計損失（E3 → 堆疊後） |
|---|---|---|---|
| 1 | **膽囊遮罩缺失時 logit 是常數**（器官不存在 → embedding 為 0 → 固定的 bias） | 遮罩 <100 vox 的陽性與陰性平均 logit 都是 **1.01**。在遮罩缺失的子群內，E3 的 AUROC 只有 **0.506**。這群陰性有 764 例，佔陰性的 6.4%：分割失敗或原因不明 477 例、膽囊收縮或未擴張 207 例、充滿結石 80 例。 | **≈0.028 → 0.005** |
| 2 | **常數 logit 落在中間，排序被打亂**：只要有膽囊的陰性分數 >1.01，就會排在所有遮罩缺失的陽性前面 | 「遮罩缺失的陽性 vs 有遮罩的陰性」這組 pair 損失 0.0117。加上「遮罩缺失」指標，或直接用體積堆疊，就降到 0.001。 | **≈0.012 → 0.001** |
| 3 | **陽性卻有非空的膽囊遮罩**（TS 把膽囊窩的腸道、積液或術後組織標成膽囊） | 350 例（陽性的 10.4%），中位數 296 vox（陰性為 1,061 vox）。HU 中位數 32.5（陰性 23.0），液體比例 0.54（陰性 0.71）。其中肝移植／Whipple 等術後解剖改變佔 31%（全部陽性為 20%）。90% 特異度下的 FN 有 **72%** 屬於這群。 | ≈0.008 → 0.006（**堆疊後的最大殘差**） |
| 4 | 標籤雜訊 | 拿掉 260 例可疑標註後，AUROC 只從 0.951 升到 0.954（堆疊 0.986 → 0.988）。可疑標註包括：陰性但報告提到切除 18 例、ch_cat=not_mentioned 161 例、寫「膽囊未顯影」18 例；陽性但報告沒有切除字樣 81 例。部分切除只有 16 例。 | ≈0.002（**不是瓶頸**） |
| 5 | 年齡 | 只用年齡的 AUROC 是 0.580。各年齡層內的 AUROC 為 0.956／0.958／0.944／0.931（<40／40–60／60–75／≥75 歲）。≥75 歲較差，是因為膽囊收縮、充滿結石的情形變多。 | 可忽略（不是捷徑） |

**手術夾特徵（H2）**：單一特徵中最強的是肝周 shell >800 HU 體素數（AUROC 0.831；>0 的比例陽性 80%、陰性 18%）和 50 mm 膽囊窩 >800 HU（0.823）；30 mm ROI 較弱（0.68），因為手術夾多在膽囊管殘端，比膽囊重心更靠內側。遮罩缺失且有手術夾的病例，陽性率 93.5%；遮罩缺失但沒有手術夾的病例，陽性率 74.1%。手術夾特徵讓遮罩缺失子群的 AUROC 從 0.506 升到 0.903。

**H1 補充**：把「遮罩 <100 vox」直接當成判斷規則，敏感度 89.2%、特異度 93.6%。另外，有 72 例陰性遮罩缺失但有手術夾，這群最可能是報告漏寫的膽囊切除。

## 3. 90% 特異度下的錯誤分類（E3_late OOF；FN 93、FP 1,189）
**FN**（括號內為該類在全部陽性中的比例）
- D 仍有膽囊遮罩（≥100 vox；TS 把窩內腸道／液體當成膽囊）：72.0%（7.0%）
- C 肝移植／Whipple 等術後解剖改變，且有遮罩：20.4%（3.2%）
- A 報告沒有切除字樣（標註可疑）：6.5%（2.4%）
- B 部分切除／殘留膽囊：1.1%（0.4%）

**FP**（括號內為該類在全部陰性中的比例）
- d 遮罩缺失，原因不明（分割失敗）：35.3%（3.5%）
- f 有正常大小的遮罩：22.5%（85.6%）
- b 膽囊收縮／未擴張，因而遮罩缺失：17.2%（1.7%）
- e 小遮罩（100–299 vox）：12.4%（7.0%）
- c 膽囊充滿結石，因而遮罩缺失：6.7%（0.7%）
- a 標註可疑（報告提到切除，或未提及膽囊）：5.7%（1.5%）

堆疊後在 90% 特異度下只剩 58 例 FN，其中 97% 有膽囊遮罩。FP 中有 62% 遮罩缺失。

## 4. 上限估計
- 目前的瓶頸**不在標籤**：清理標籤只增加約 +0.002。
- 堆疊後剩下的損失（0.014）來自兩類：陽性卻有假膽囊遮罩（約 0.006），以及陰性的膽囊沒被分割出來（約 0.006）。
- 以凍結 encoder、3 mm 影像為前提，實際上限約 **0.99**。若改善分割（fallback），還可再增加約 +0.003～+0.006。

## 5. 建議修正（前三名）
1. **E3_late＋膽囊體積／形態＋膽囊窩＋手術夾特徵，做 late stacking（HGB）**
   - 預期增益：train OOF **+0.035**（0.951 → 0.986）；val 描述 **+0.034**（CI +0.030～+0.038）。
   - 成本：低。特徵已算好；test 鎖定設定後只需跑約 30 分鐘 CPU（`ag_feat.py`）。
   - 最簡版本：E3_late 加上「遮罩缺失」指標與 log 體積（LR），就有 +0.020。
2. **膽囊遮罩缺失時的 fallback**：佔陰性的 6.4%，包括膽囊收縮、充滿結石、分割失敗。做法是遮罩 <100 vox 時，改用膽囊窩 ROI crop 取 embedding，或用 TS 1.5 mm 完整模型重新分割膽囊。也可把膽結石 head 的分數和膽囊窩的 HU 分布當成特徵。
   - 預期增益：+0.003～+0.006。
   - 成本：中。需重新抽取約 3,800 例 train／val 的 embedding（GPU 或 CPU）。
3. **膽囊遮罩 QC**：用與肝的接觸比例、腸道接觸、HU／液體比例、體積，判斷遮罩是不是真的膽囊。不像膽囊的遮罩改當成「不存在」，或另外輸入一個「像膽囊程度」的分數。針對肝移植／Whipple 後的病例特別有用。
   - 預期增益：+0.002～+0.004。
   - 成本：低到中。主要是規則與特徵工程，部分已含在修正 1 的 HGB 中。

不建議優先做：標籤清理（+0.002）、加年齡／性別（+0.000）、更換 window（E1 各 window 的差異只有 ±0.004）。
