## 0. 規則（所有疾病一致）
- 只用 train＋val：先依 split.csv 過濾，再讀標籤；expB 的 probe npz 只取 val 列（test 列立即丟棄、從未使用）。
- **選模只看 train 5-fold OOF**，fold 沿用各疾病自己的 E3_late OOF fold（同一個疾病內一致）。候選：LR（C 0.1／0.3／1，class-balanced）與 4 組 HistGBM（與 gallstones_improve 相同的格點）；特徵組合 = 各 head 組合 × {只有 head、head＋影像特徵（全部或精選子集）}。選定後用全部 train refit，val 只套用一次。
- val 指標：AUROC＋分層 bootstrap 95% CI（2,000 次）；Δ 為相對 **expB E3_late val（3 seed 平均機率）** 的 paired bootstrap；年齡配對 AUROC（10 歲年齡層內配對，依配對數加權）；陰性中分數與年齡的 Spearman；90% 特異度敏感度（val 自身閾值）。
- **年齡／性別從未作為模型輸入**；骨質減少 bundle 裡的 metadata 欄位一律剔除。標籤定義未更動（脂肪肝、闌尾炎拆分列為額外列）。
- 計算：CPU only（nice 19、≤4 threads）；train/val 切片在 Mac／CT-rate 上計算後已刪除。

## 3. 各疾病說明與注意事項
- **骨折**：依協調者決定，正式列採 **Exp J add 10 seed**（val .847、年齡配對 .829、椎體壓迫性 .933）。依 train OOF 嚴格挑選的話，Exp J 的 S3／S4 stacker（stacker CV .855）略高於 J add（.853），但 val 只有 .838；兩者 OOF 差距 .002，在誤差範圍內，因此採用較簡單、val 較好的 J add，這點要如實揭露。**Exp I 集成（.835）** 列為「只用 3 mm、可直接部署」的替代版。骨折 val 是 Exp J 共同集 4,946 例（556 個陽性中有 553 個）。
- **膽結石**：GS5 G5c（train OOF .875，所有 GS 版本中最高）。G5c 不含其他 13 個疾病的 head，所以沒有借用年齡代理 head（G4 用到 o13_atherosclerosis，這次沒有被選上）。
- **膽管擴張**：BD5 的 GBM（加入肝門 crop embedding，train OOF .910）。bd_stack.py 沒有存模型檔；`random_state=0` 可以重現，重跑 `bd_stack.py work out` 會得到同一個模型。
- **腎水腫**：選出的是 E3_late＋兩腎 MIL max head＋液體 HU（GBM）。val .944，比錯誤分析預期的 .939 略高。
- **腹腔游離氣體／腹水／腸阻塞／骨質減少**：原本缺少的特徵已經**全部補齊**：
  - 空氣：A6000 補 4,409 例。
  - 腹膜腔積液：12,864 例，由 Mac、CT-rate 以 train/val 切片計算。
  - 腸道口徑：1,518 例。
  - 骨小樑核心 HU：10,862 例。
  - 補齊後覆蓋率 train／val 都是 100%，是同一支程式算的；切片用完已刪除。
- **骨質減少**：train OOF 選中「5 個 window logit 的 LR」（.904）。加入骨小樑 HU 的版本沒有勝出。val .884（+.003，CI 跨 0），結論同錯誤分析：問題在標籤，模型端沒有空間。
- **脾腫大**：+.001（CI 跨 0），已接近天花板。
- **年齡**：沒有任何疾病的年齡配對 AUROC 下降。動脈粥狀硬化的年齡配對 AUROC 從 .703 升到 .779，但陰性中分數和年齡的 Spearman 仍有 .81，主要訊號仍與年齡高度相關，報告時應並列年齡配對 AUROC。
- **拆分標籤**：
  - 脂肪肝：直接採用 steatosis_split 的輸出，取 train OOF 最高的版本（瀰漫性 E3＋HU、局部 E3＋HU＋FL）。
  - 闌尾炎：appendicitis_split 的 stack 評估還沒完成時，我用它已完成的 probe OOF head（E3_late、大腸＋小腸、trap 版大腸＋小腸 E3cs_trap），在同一框架內做 stack，候選與選模規則相同。兩個定義都選中「E3_late＋E3cs_trap＋RLQ 局部 HU」。
  - 確定急性 val .901（+.042，年齡配對 .834 → .889）。
  - 可疑等只有 26 個 val 陽性，val .819，**年齡配對下降（.817 → .790）⚠**，不建議當主要指標。
- **腹主動脈瘤**：val 只有 32 個陽性，.990 的 CI 寬，小數點第三位不可信。

## 5. 可重現性與檔案
- `integrated_per_finding.csv`：本表全部數字，包含 train OOF、Δ CI、年齡配對、Spearman、敏感度。
- `main_all.json`：main_all 前後與 CI。
- `results/<finding>.json`：每個疾病的完整指標，以及所有候選模型的 train OOF。
- `scores/<finding>_{oof,val}.csv`：每例分數，只有 train／val。
- `models/<finding>.joblib`：stack 模型、前處理（log 欄位、補值中位數）、欄位順序、train OOF 的 90% 特異度閾值。
- `models/<finding>_features.json`：特徵清單。
- 膽結石模型：`models/gallstones_stack_G5c.joblib`（複製自 gallstones_improve/gs5/stack）。
- 程式（`scripts/`）：
  - `ib_core.py`：共用指標與候選模型。
  - `ib_stack.py`：選模、refit、val 評估。
  - `ib_external.py`：膽結石／膽管擴張／骨折。
  - `ib_split.py`：拆分標籤的額外列。
  - `ib_summary.py`：main_all。
  - `ib_report.py`
  - `ib_apply.py`：用存好的 stack 給新資料打分數。已在 val 驗證重現（與存檔分數差 0.0）。
  - `ib_test_heads.py`：用原 OOF 程式、同樣的 seed refit probe head，對 test 列打分數。
  - **`rebuild_test_features.sh`**：一支程式重建 test 的全部輸入（影像特徵 → probe head → apply）。必須設定 `IB_TEST_LOCKED=yes-locked-by-user` 才會執行，**本次沒有執行**。
  - `analysis_code/`：凍結的特徵與 OOF 程式副本。
- 補算的特徵：`features/`，只有 train／val。
- 版本：scikit-learn 1.9.1（Mac 與 A6000 radar env 相同）。
