- Azure 每連線僅 ~1.25 MB/s，改用 Mac 外接 Passport 的原始 CT。train 分層抽樣 580 例（陽性 310：僅肝外 80、支架/氣膽 30、輕度 110、中重度 50、未註明 40；陰性 270：支架/氣膽 30、probably_no 50、膽囊切除 60、其他 130），反機率加權；579 例成功（1 例無 PV）。

- **只在 pilot 內評估**（20 次重複 5-fold，同一切分配對比較）：
  - 單一特徵：原始解析度 CBD 最大徑 n_hdl_cbd_dmax 加權 AUROC **.758**，與 3 mm 的 porta_fluid_maxcc **.762** 相當；3 mm HDL 最大徑只有 .670（3 mm 解析度上限）。

  - 輕度：3 mm .811 vs native .806；**僅肝外：3 mm .814 vs native .817（+.003，75% 切分較好）**。
- **結論：原始解析度沒有帶來超越 3 mm 特徵的增益（僅肝外 +.003，在雜訊內）。不建議擴大。** 成本估計：全量 20,364 例 × 26 秒 ÷ 4 行程 ≈ 37 小時（Mac＋Passport 單碟讀取是瓶頸）；Azure 1.25 MB/s × 每例 ~140 MB ≈ 2 分鐘/例/連線，不可行。
