# 動脈粥狀硬化：錯誤分析（train 5-fold OOF）

日期：2026-11-05｜主機：A6000 `~/Desktop/Tony/VLM/OWL/mw_exp/outputs_final/analysis_atherosclerosis/`｜**test 未讀取、未評分**

## 0. 方法
- 分析資料：train（陽性 5,050／陰性 10,217，排除 unclear 42 例）。用 probe.py 的設定跑 5-fold OOF：主動脈單元（finding_organ_map 中動脈粥狀硬化只對應 `aorta`，**不含髂動脈**）、標準化、class-balanced BCE、lr 1e-3／wd 1e-4（expB 選出的超參數）。early stopping 改用 train fold 內 15% 的 holdout，不看 val。聯合訓練的 finding 只放同屬主動脈單元的 動脈粥狀硬化＋腹主動脈瘤。E0／E3_late 各 2 個 seed 取平均，E1 各 1 個 seed。
  - A6000 CPU 負載過高（load 約 50），OOF 改在 Mac 上用同一份 notest embedding、同一份 `probe.py`（內容與 A6000 相同）執行，nice 19、4 threads，沒有用 GPU。
- 重現檢查（val，只描述）：本流程 E0 0.886、E3_late 0.885；expB 原始結果是 0.886／0.888，一致。
- HU 特徵：從 3 mm prep 的 HU 與 TS fast 多標籤遮罩（同一個 3 mm grid）計算，涵蓋 train＋val 全部 20,364 例（CT-rate 11,355、A6000 2,500，另外 6,509 例因 A6000 負載太高，暫時把 prep 與遮罩複製到 Mac 計算，算完已刪除）。
  - 區域：主動脈（TS 52）＋左右髂動脈（65、66）。「壁殼層」＝ 遮罩向外膨脹 2 voxel、扣掉向內侵蝕 1 voxel 的核心，只保留背景或血管 label（排除脊椎、靜脈、腸道等）。
  - 管腔 HU：主動脈核心的中位數（顯影相位的代理指標）。閾值用絕對值（130／200／300／400／600 HU）與適應性閾值（A＝max(130, 管腔+100)，B＝max(200, 管腔+200)）。特徵包括超過閾值的 voxel 數、超過量總和（類 Agatston 的 mass）、連通塊數、有鈣化的切片比例。
  - 鈣化分數 `calc` ＝ log1p(主動脈＋髂動脈壁殼層的 massA)。
- 文字特徵：只用 train／val 報告中含血管相關字詞的句子做關鍵字比對，另外使用 Qwen 標註的 `grade`／`aortoiliac` 欄位。
- 堆疊：與 OOF 共用同一組 fold，做 logistic regression（C=0.3，class-balanced）或 HistGradientBoosting（GBM）。

## 2. 原因排序（依估計的 AUROC 損失）
估計方式：AUROC ＝ 每個陽性「贏過幾成陰性」的平均。某一群陽性（或陰性）的損失 ≈ 該群比例 ×（其他人的平均名次 − 該群平均名次）。各項之間有重疊，不能直接相加。

| # | 原因 | 證據（train OOF） | 估計損失 |
|---|---|---|---|
| 1 | **模型主要在估年齡，而不是在看鈣化** | 只用年齡 AUROC 就有 **0.859**。在陰性中，E3 分數和年齡的 Spearman 是 **0.855**，鈣化分數和年齡只有 0.45。每 5 歲分層的年齡配對 AUROC：E3_late 只有 **0.699**（E0 0.694），各年齡層內 0.69–0.71（<50 歲 0.84）。<60 歲的陽性佔 22.8%，平均名次 0.73（其他陽性 0.92）。FN 中 47.8% 小於 60 歲（全部陽性只有 22.8%）；FP 中 54% ≥70 歲（全部陰性只有 8.8%）。主動脈體積和年齡相關（Spearman 0.51），體積最大四分位的 AUROC 只有 0.781。 | **≈0.044**（年輕陽性）；0.88 中大部分來自年齡 |
| 2 | **標籤雜訊：陰性中有不少其實有鈣化，只是報告沒寫** | 12.0% 的陰性屬於「可疑陰性」：7.4% 的陰性鈣化分數 ≥ 陽性中位數（not_mentioned 7.6%；明確寫「no」的 5.3%）；另有 4.1% 的陰性報告提到血管鈣化或斑塊，但 Qwen 沒有標為陽性（這群的 E3 AUROC 只有 0.702）。拿掉可疑陰性後：E3 0.880 → **0.913**，E3+HU 0.903 → **0.938**。陽性 vs 明確寫「no」的陰性 0.913；陽性 vs not_mentioned 0.878。 | **≈0.033**（大多是評估本身的上限，不是模型能修的） |
| 3 | **鈣化訊號被 mean pooling 稀釋，而且單元不含髂動脈** | 只用 HU 鈣化特徵（0.896）就比整個 embedding（0.880）高。年齡配對 AUROC：E3 0.699 → HU 0.765 → E3+HU 0.767；≥60 歲：E3 0.742 → E3+HU 0.780。只有主動脈的 HU（0.879）加上髂動脈後變 0.890（+0.011）；embedding 單元目前沒有髂動脈。 | **≈0.023**（加入 HU 特徵堆疊即可救回；val +0.028） |
| 4 | **輕度（mild）動脈粥狀硬化** | Qwen grade=mild 佔陽性 16.4%，AUROC **0.784**；moderate 0.925、severe 0.965、not_stated 0.886。報告用「mild／scattered／minimal」等字眼的陽性（28.5%）為 0.836。FN 中 29.1% 是 grade=mild（全部陽性中 16.4%）。輕度和中度以上的鈣化分數中位數：8.6 vs 10.6–11.5，和陰性（6.6）重疊很大。 | ≈0.018（和 #1、#2 重疊） |
| 5 | 顯影相位 | 門脈相 0.880、未打顯影劑 0.887（n=897）、arterial_late 0.886（n=131）。管腔 >300 HU 的 AUROC 0.837，但只有 62 例。HU 特徵在各相位都差不多（0.896–0.898）。 | 可忽略（<0.003） |
| 6 | multi-window 沒有幫助 | 各 window logit 的平均相關 **0.915**，資訊高度重疊。bone（0.877）≈ baseline（0.878），其他窄 window 反而較差（liver 0.841）。詳見第 5 節。 | 0（不是損失，只是沒有增益） |

補充：
- 報告中提到髂動脈（aortoiliac）的陽性 AUROC 0.891，比其他陽性（0.877）高，不是弱點。
- 同時提到冠狀動脈鈣化的陽性 0.935（多半是嚴重、年長）。
- 適應性閾值的效果不如預期：在 3 mm、線性內插的 HU 上，97% 的陰性在壁殼層至少有一個 voxel 超過「管腔＋100 HU」（顯影管腔的部分容積效應），所以「有沒有鈣化」的 0／1 幾乎沒有鑑別力。有效的是**量**（>400 HU voxel 數、mass、切片比例）。

## 3. 90% 特異度下的錯誤分類（E3_late OOF；FN 1,906、FP 1,022）
**FN**（括號內為該類在全部陽性中的比例；類別依序判定）
- B 輕度（grade=mild 或報告寫 mild／scattered 等）且有鈣化：38.5%（28.4%）
- C 鈣化量低（< 陽性第 25 百分位）：30.3%（13.8%，約 2.2 倍）
- D <60 歲、有一定鈣化：12.5%（8.1%）
- E 鈣化明顯、年紀大，但仍漏掉：18.2%（49.5%）
- A 完全沒有偵測到鈣化：0.6%（0.2%）
- 整體：FN 中 47.8% 小於 60 歲（全部陽性 22.8%）。

**FP**（括號內為該類在全部陰性中的比例）
- A 鈣化量 ≥ 陽性中位數，或報告有提到血管鈣化／斑塊（**很可能是漏標**）：**52.7%（12.0%，約 4.4 倍）**
- C 中等鈣化量：12.8%（4.6%）
- B 腹主動脈瘤或支架／移植物：19.1%（28.3%，沒有富集；「支架」關鍵字也會抓到輸尿管支架等，僅供參考）
- D ≥70 歲、鈣化少：4.6%（1.7%）
- E 其他：10.8%
- 整體：FP 中 96% 是 not_mentioned，54% ≥70 歲（全部陰性 8.8%）。

## 4. 上限估計
- 以目前的 Qwen 標籤評估：E3+HU+年齡 0.906（OOF），val 描述 0.913。12% 的可疑陰性平均只贏過 36% 的陽性（正常陰性只贏過 9%），在不修標籤的前提下，**實際上限約 0.91–0.92**。
- 若可疑陰性改為陽性或排除：E3+HU 達 **0.938**，HU 單獨 0.932，代表影像本身足以把乾淨標籤做到約 0.94–0.95。
- 年齡配對的上限：目前最好的是 E3+HU 0.767。真正的「影像訊號」比總體 AUROC 看起來弱很多；0.88 中約 0.86 單靠年齡就能得到。

## 5. 為什麼 multi-window 沒有增益
1. **鈣化在 baseline 就看得到**：baseline 的 nnU-Net CTNormalization 把 HU clip 在約 −1004～1588，鈣化（數百～上千 HU）完整保留；bone window（L400/W1800，約 −500～1300）幾乎是同一個資訊，所以 E1_bone（0.877）≈ E0（0.878）。
2. **窄 window 把鈣化和顯影管腔一起截掉**：soft_tissue（上限 240 HU）、narrow_abd（165）、liver（135）在門脈相時，管腔（中位數約 150–200 HU）和鈣化都被壓到最大值，兩者分不開。因此這三個 window 都比 baseline 差（0.841–0.861）。
3. **瓶頸不在 window，而在 pooling 與年齡**：五個 window 的 logit 相關 0.915；模型分數和年齡的相關（0.855）遠大於和鈣化的相關。器官平均 pooling 讓少數鈣化 voxel 被大量管腔 voxel 稀釋，embedding 主要反映主動脈的大小、形狀與周圍組織，也就是年齡。HU 鈣化特徵在年齡配對下仍有 0.765，E3 只有 0.699。

## 6. 建議修正（前三名）
1. **加入主動脈＋髂動脈壁的鈣化 HU 特徵，做 late stacking（GBM）**：壁殼層 >300／>400 HU 的 voxel 數、massA、nB、有鈣化的切片比例、連通塊數、管腔 HU、主動脈與髂動脈體積。
   - 預期增益：train OOF **+0.023**（0.880 → 0.903），val 描述 **+0.028**（0.885 → 0.913）；年齡配對 AUROC +0.07（0.699 → 0.767）。
   - 成本：低。train／val 特徵已算好；test 只需在鎖定設定後跑約 30 分鐘 CPU。
2. **處理標籤雜訊**：用同義詞（vascular／aortic／iliac calcification、calcified plaque、atheromatous）重新判讀 not_mentioned 的報告；鈣化分數高但報告未提的陰性，訓練時改為 unclear（排除）或 soft label。另外加報「陽性 vs 明確寫 no 的陰性」與年齡配對 AUROC。
   - 預期增益：評估上 +0.03（0.880 → 0.913，屬於標籤修正，不是模型進步，必須另外標示）；訓練面約 +0.005～0.01（未驗證）。
   - 成本：低～中。Qwen 重跑約 4,000 份報告；需要決定是否改變 benchmark 定義。
3. **改善表徵：髂動脈併入單元＋高 HU pooling，並做去年齡化**：主動脈單元加入 iliac_artery_left／right（或另立 aortoiliac 單元）；pooling 增加 max 或「>300 HU voxel 比例」通道；可考慮 1.5 mm 主動脈 crop；搭配已有的 trap（去年齡捷徑）訓練。
   - 預期增益：約 +0.01～0.02（髂動脈在 HU 特徵上 +0.011，可作為參考）；年齡配對 AUROC 預期提升更多。
   - 成本：中～高，需要 GPU 重新抽取 embedding。

不建議優先做：依顯影相位分組（差異 <0.01）、增加窄 window（會截掉鈣化）。年齡／性別加進模型只 +0.004，而且屬於捷徑，不應計入。
