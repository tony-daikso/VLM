# 腹水：錯誤分析（train 5-fold OOF）

日期：2026-11-05｜檔案：A6000 `~/Desktop/Tony/VLM/OWL/mw_exp/outputs_final/analysis_ascites/`｜**test 未讀取、未評分**

## 0. 方法
- **資料**：只用 train（陽性 3,015／陰性 12,070，排除 unclear 224 例）。陽性定義和 probe 相同：yes＋probably_yes；陰性為 no＋probably_no＋not_mentioned。
- **OOF**：依 probe.py 的設定做 5-fold OOF。單元用 finding_organ_map 的 liver＋spleen（取存在單元的平均，再加上存在比例特徵），沿用標準化方式（12 個主單元合併統計），class-balanced BCE，lr 1e-3／wd 1e-4（expB 選出的超參數）。early stopping 改用 train fold 內 15% 的 holdout，不看 val。只訓練腹水一個 finding。E0／E3_late 各跑 2 個 seed，其他設定 1 個 seed。
- **重現檢查**（val，只做描述）：本流程 E0 0.865、E3_late 0.882；expB 是 0.866／0.883，一致。
- **HU／遮罩特徵**：在 CT-rate CPU 上，從 3 mm prep 的 HU 和 TS total 117 類遮罩計算。因為主機很忙，只隨機抽樣 **train 6,000 例＋val 1,500 例**。這個子集上 E3_late 的 AUROC 是 0.884，和全體 0.885 幾乎相同，代表抽樣有代表性。
  - 腹膜腔代理：從肝頂到骨盆底，每一層取腹部器官／骨頭的 2D 凸包，外擴 6 mm，再扣掉所有 TS 標籤（外擴 3 mm）。距肺 9 mm 以內的體素另外算成肋膜積液。
  - 積液：先做 3-tap 中位數濾波，再取 0–30 HU；另外統計 ≥10 體素連通塊的體積、最大連通塊、肝周／脾周殼層（3–9 mm）、骨盆（L5 以下）、膀胱周圍、皮下脂肪 HU 與水腫比例、腸系膜脂肪 HU、腸道內液體，以及各 HU 區間的體積。
- **文字旗標**：只用 train／val 的報告和 Qwen 引文，以關鍵字比對（另外排除含否定詞的句子）。只保存旗標，不保存原文。
- **堆疊**：和 OOF 共用同一組 fold，做 logistic regression（C=0.3，class-balanced）。

## 2. 原因排序（依估計的 AUROC 損失）
| # | 原因 | 證據（train OOF） | 估計損失 |
|---|---|---|---|
| 1 | **少量腹水本身難判讀** | 陽性有 54% 是 small。各量級的 AUROC：small 0.830、moderate 0.948、large 0.987。trace 幾乎全被標成陰性（見 #2）。small 陽性的積液特徵中位數 553 ml，陰性是 344 ml，兩者重疊多（這個代理量有一個約 340 ml 的底噪，主要來自未標註的軟組織）。「只在骨盆的少量」AUROC 0.807。 | 上界 ≈0.064（假設 small 能做到 moderate 的水準）。實際可救回的不多：堆疊或 all12 只能把 small 提高到 0.84–0.85。 |
| 2 | **標籤邊界不一致**（微量／少量積液怎麼判，前後不一） | Qwen 把 1,525 例 trace 和 1,277 例 small 標成 probably_no（理由多半是「below the cut」或「physiologic」），合計 2,802 例，佔陰性 23%。但另外 1,623 例 small 卻標成 yes。這群陰性在 90% 特異度下的 FPR 是 17–18%，乾淨的「no」陰性只有 6.9%。把這群拿掉，AUROC 從 0.885 升到 **0.899**。small 陽性 vs small 陰性的 AUROC 是 0.756，表示仍可部分區分，兩者確實有量的差異，不完全是隨機標註。 | **≈0.014**（評估定義造成的損失；重新訓練救不回：dropamb ±0、anyfluid −0.015） |

## 3. 90% 特異度下的錯誤分類（E3_late OOF；FN 900、FP 1,207）
**FN**（括號內為該類在全部陽性中的比例；依序歸類，每例只歸一類）
- D 少量（small）：**69.9%**（47.1%）
- B 報告用語不確定：12.1%（13.2%）
- F 中量～大量卻仍漏掉：11.1%（31.9%）
- G 未註明量：5.8%；A probably_yes：1.0%
- FN 的積液特徵中位數 435 ml，介於 TP（944）和 TN（332）之間，和 FP（577）接近。

**FP**（括號內為該類在全部陰性中的比例）
- a 報告有提到少量／微量積液，但被標為陰性：**45.7%**（25.1%），即標籤邊界問題
- b 局限性積液／膿瘍：21.3%（10.8%）
- d 肋膜積液：11.6%（13.2%）
- i 術後：4.6%；c 血腫：2.2%；f 肝硬化：1.9%；e 全身水腫：1.5%（0.6%）；j 腸阻塞：1.5%（0.7%）；其他：7.9%（32.6%）
- FP 的皮下水腫比例中位數 0.21，TN 為 0.11、TP 為 0.29，表示 FP 多半是全身水腫或病況較重的病人。

## 4. 上限估計
- 目前的標籤：凍結 encoder＋all12＋HU 特徵，實際上限約 **0.90–0.91**。
- 標籤邊界清乾淨後（排除模糊陰性與用語不確定的陽性）：E3_late 0.902、堆疊 0.912。
- 不計 small 陽性時：E3_late 0.951、堆疊 0.962。真正難的核心是「少量、孤立、只在骨盆」的腹水，要再往上需要更高解析度或專門的腹膜腔表徵。

## 5. 建議修正（前三名）
1. **把腹水對應到全部單元（或包含腸道）＋腹膜腔積液 HU 特徵堆疊**
   - 預期增益：all12 單獨 +0.008（train OOF 與 val 一致）；再加 HU 特徵約 +0.015（HU 子集，95% CI 下限 > 0），val 描述 +0.015。
   - 成本：低。all12 只要改 finding_organ_map 並重跑 probe。HU 特徵約每例 1 CPU 秒，但目前只算了 7,500 例，全量 train／val／test 還要補算（在鎖定設定後跑 test）。
2. **新增「腹膜腔」單元的 embedding**：用本分析的腹膜腔代理遮罩（凸包扣掉器官），加上肝周／脾周殼層和骨盆區，做 pooling；可以考慮加上 0–30 HU 體素比例的通道。
   - 預期增益：約 +0.01～+0.02（推估，未實測），主要針對 small 和只在骨盆的腹水。
   - 成本：中。需要用 GPU 重新抽取一個單元的 embedding。
3. **重新定義微量／少量積液的標籤**：改成三級（無／微量～少量游離液／腹水），或把「probably_no 但有提到積液」的 2,802 例改成 unclear，不納入評估。
   - 預期增益：評估上 +0.014（同一個模型）。這是定義問題，重新訓練救不回（dropamb ±0；anyfluid 在舊標籤上 −0.015）。
   - 成本：低，可以直接用 Qwen 標註裡的 `detail.amount` 重建標籤，但要先決定評估定義，並且 val 和 test 要一致套用。

不建議優先做：換 window（單一 window 都沒有比較好）、校正年齡（沒有年齡捷徑）、依顯影相位分組（沒有差異）。
