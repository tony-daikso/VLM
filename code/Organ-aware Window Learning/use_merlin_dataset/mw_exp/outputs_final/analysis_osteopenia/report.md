# 骨質減少：錯誤分析（train 5-fold OOF）

日期：2026-11-05｜主機：A6000 `~/Desktop/Tony/VLM/OWL/mw_exp/outputs_final/analysis_osteopenia/`｜**test 未讀取、未評分**

## 0. 方法
- 分析資料：train（陽性 712／陰性 14,544，排除 unclear 53 例）。用 probe.py 的設定跑 5-fold OOF：lumbar_spine 單元、標準化、class-balanced BCE、lr 1e-3／wd 1e-4（expB 選出的超參數）。early stopping 改用 train fold 內 15% 的 holdout，不看 val。實驗 B 之後 lumbar_spine 只對應骨質減少，所以是單一 finding。E0、E3_late 各跑 2 個 seed 取平均。
- 重現檢查（val，只描述）：本流程 E0 0.878、E3_late 0.882；expB 原始結果是 0.880／0.881，一致。
- 骨密度 HU 特徵分兩層：
  - **全覆蓋（99.7%）**：沿用 `fracture_features.py` 的結果。每節椎體（取 AP 方向前 40%）的 HU 中位數與 p10，記為 `L1c`。這個值含皮質骨的部分容積，比真正的骨小樑 HU 高。
  - **骨小樑核心（子集 46.7%，train 陽性 308／陰性 6,816）**：新寫 `op_hu.py`，從椎體 mask 在平面內侵蝕 1 voxel（約 3 mm 皮質）後取中位數與 p25，另外計算椎旁肌、腰大肌的 HU。這部分在 CT-rate、A6000 以 nice 19 跑。因為兩台主機都滿載，跑到約一半就停了；子集依 id 排序，等同虛擬隨機抽樣，核心 HU 與椎體 HU 的相關為 0.958。
- 主動脈 HU 讀自 gallstones 分析（唯讀），用來判斷顯影相位；年齡、性別、相位取自 metadata。文字旗標只從 train／val 報告做關鍵字比對，不輸出原文。
- 堆疊：與 OOF 共用同一組 fold，做 logistic regression（C=0.3，class-balanced）。

## 2. 原因排序（依估計的 AUROC 損失）
| # | 原因 | 證據（train OOF） | 估計損失 |
|---|---|---|---|
| 1 | **標籤定義：報告低報骨質減少（主要上限）** | 核心 HU <110（骨質疏鬆範圍）的病例中，只有 **27%** 被報告；<160 只有 14.5%。陰性中 **17.2%** 的核心 HU <160，在子集內有 1,172 例，是陽性（308 例）的 **3.8 倍**。≥80 歲的陰性有一半 <160。拿掉核心 HU <110／<130／<160 的陰性後，E3_late 從 0.902 升到 **0.913／0.925／0.945**。90% 特異度下，FP 的 HU 比 FN 低的機率是 **0.70**（FP 中位數 169 HU，FN 204 HU），也就是影像比較支持模型、不支持標籤。 | **≈0.02–0.045**（模型改不動，需要改標籤） |
| 2 | **陽性本身不一致：報告是「印象」，不是密度門檻** | 36% 的陽性核心 HU ≥160，63% 的陽性椎體 HU ≥160。這組 AUROC 只有 **0.866**；椎體 HU 110–160 的陽性是 0.954，<110 的是 0.983。報告寫「mild」的陽性 AUROC 0.761。理想的 HU 門檻偵測器拿報告標籤當答案，AUROC 也只有 0.59–0.74，可見報告標籤不是 HU 門檻。 | ≈0.02–0.03（與 #1 同源） |
| 3 | **年齡混淆：大部分分數來自年齡** | 只用年齡的 AUROC **0.827**；E3 分數與年齡的相關是 0.67。年齡×性別配對後，AUROC 從 0.900 掉到 **0.788**。67% 的陽性 ≥70 歲，而 ≥60 歲各層的 AUROC 只有 **0.74–0.81**，同一層內 HU 的 AUROC 只有 0.55–0.68。 | 不算損失，但表示 0.90 被高估；同一年齡層內真正的影像訊號約 0.79 |
| 4 | **與骨折、椎體成形術一起報告** | 34% 的陽性同時有骨折標籤（陰性 9.8%），23% 提到壓迫性骨折（陰性 7.1%），4.2% 做過椎體成形術（陰性 0.5%）。有骨折的陽性 AUROC 0.950，沒有骨折的是 0.875。有骨折的陰性分數平均排在陰性的第 68 百分位，佔 FP 的 27.6%（基準 12.3%）。 | ≈0.01（一部分其實是漏標） |
| 5 | 絕對 HU／mean pooling 稀釋骨小樑 | **不成立**。embedding 可以線性解碼 L1 HU：lumbar_spine R² 0.75、L1 單元 R² 0.85（MAE 16–19 HU）。核心 HU 單獨用比椎體 HU 好（p25 0.825 vs 0.765），但堆疊到 E3_late 上只有 −0.002～+0.004。 | ≈0–0.004 |
| 6 | 顯影相位 | 98.6% 是門脈相。未打顯影劑的 E3 AUROC 0.909（44 陽性），門脈相 0.900。每 100 HU 主動脈 HU，L1 HU 約上升 17 HU；相位校正只讓 HU 單獨的 AUROC 從 0.761 升到 0.767。 | 可忽略 |
| 7 | multi-window 沒有增益 | 見第 5 節 | ≈0.003 |

## 3. 90% 特異度下的錯誤分類（E3_late OOF；FN 216、FP 1,455）
**FN**（括號內為該類在全部陽性中的比例）
- C 椎體 HU 正常（≥160）：**86.1%（59.8%）**。這些陽性影像上看不出密度低，中位年齡 68 歲（TP 是 81 歲）。
- E HU 介於 110–160：9.3%（26.8%）
- D 年輕（<60 歲）且 HU 偏低：3.2%（4.4%）
- B 椎體成形術後、F HU <110 但仍漏掉：合計 1.4%
- 報告寫「mild」的佔 FN 6.0%（佔全部陽性 3.1%）

**FP**（括號內為該類在全部陰性中的比例）
- f HU 正常但高齡（≥70 歲）：29.4%（13.0%）
- d 有骨折／壓迫性變形，報告沒提骨質減少：**27.6%（12.3%）**
- e HU 110–160（灰色地帶）：**24.3%（4.7%）**
- c L1 HU <110，疑似漏標：4.1%（0.6%，約 7 倍）
- b 椎體成形術後：2.6%（0.5%）
- g 其他：11.8%（68.6%）

整體來看，FP 中位年齡 77 歲、L1 HU 169；TN 是 52 歲、246 HU。多數 FP 是高齡、HU 偏低或有骨折的病人，臨床上很可能真的骨質減少，只是報告沒寫。

## 4. 上限估計
- 用報告標籤評估時，不論怎麼組合（window logit、HU、肌肉、年齡），train OOF 都停在 **0.903–0.904**。
- 只和明確正常的陰性比（L1 HU ≥160），AUROC 是 0.923。拿掉疑似漏標的陰性（核心 HU <130）後是 0.925。
- 估計以凍結 encoder 加報告標籤的實際上限約 **0.91–0.92**。剩下的落差主要是標籤問題，不是模型問題。若改用 HU 定義的標籤，或排除疑似漏標的陰性，AUROC 可到 0.93–0.95，但那等於換了任務。
- 同一年齡層內的影像訊號（年齡×性別配對 AUROC）目前約 0.79。這才是比較誠實的模型能力指標。

## 5. 為什麼 multi-window 沒有增益
- 骨質減少是**整體密度**的問題。baseline 的 CTNormalization 對 −1004～1588 HU 是線性的，骨小樑的範圍（約 50–300 HU）在裡面沒有被截斷，資訊已經完整。
- 窄 window 會把骨頭截掉：soft_tissue 上限 240 HU、narrow_abd 165、liver 135，骨小樑大多被壓成 1。bone window（−500～1300）則把骨小樑壓縮在很窄的灰階裡。所以其他 window 不會帶來新資訊：各 window 的 OOF 分數與 E0 的相關是 0.87–0.94；bone window 0.899 和 E0 0.898 幾乎一樣。
- 各 window 解碼 L1 HU 的 R²：baseline 0.754、bone 0.754、soft_tissue 0.743、narrow_abd 0.664、liver 0.627。窄 window 解碼得比較差，和截斷的推論一致。
- 注意：17 個骨骼單元的 embedding（emb_bones）中，soft_tissue／liver／narrow_abd 三個 window 的值**完全相同**。可能是骨骼單元在窄 window 下整塊飽和，也可能是抽取時沒有真的換 window，建議另外確認。

## 6. 建議修正（前三名）
1. **修正標籤與評估方式**：把「未提及」且 L1 核心 HU <110（或 <130）的高齡陰性改成不確定（排除，或給 soft label／PU learning）。另外加一個客觀的輔助目標：以 L1 骨小樑 HU（<160／<110）定義的「影像骨質減少」，和報告標籤一起報告。
   - 預期增益：用清理後的標籤評估 +0.01～+0.025；用原始標籤評估，訓練端處理雜訊陰性約 +0.005。
   - 成本：低。核心 HU 程式已完成，補跑剩下約 53% 的 train／val 需要 1–2 小時 CPU；test 等設定鎖定後再跑。
2. **堆疊 5 個 window 的 logit**，取代 E3_late 的 gate，必要時再加骨小樑核心 HU 與椎旁肌 HU。
   - 預期增益：window 堆疊 +0.003（0.900 → 0.903）；在核心 HU 子集上，加核心 HU 與肌肉 HU 是 +0.004，年齡配對 AUROC +0.009（0.784 → 0.793）。
   - 成本：很低，只需要 LR。
3. **以年齡配對 AUROC 為主要指標，並用 trap 去年齡捷徑**；另外讓骨質減少和骨折、椎體成形術做多任務聯合訓練，或把骨折 head 的分數當成特徵。
   - 預期增益：原始 AUROC 約 0～+0.005，但能讓結果更可信（目前 0.90 中約 0.11 來自年齡分層）。
   - 成本：低到中。

不建議優先做：高解析 crop 或 finetune 去抓骨小樑（embedding 已經能解碼 HU，R² 0.75–0.85；HU 堆疊不加分）、相位校正（98.6% 是門脈相，沒有差異）、新增 window（原因見第 5 節）。
