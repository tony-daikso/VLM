# 膽結石：Exp N × G6c 組合（gallstones_final）

日期：2026-11-06｜計算：Mac CPU（nice 19、4 threads），使用只含 train／val 的資料切片，結束後已刪除｜**test 未讀取**

## 0. 結論
- 依 train OOF 選出的是 **(c) 等權 z-score 平均（Exp N 的 N_U＋G6c，不調權重）**：train OOF 0.879 → **0.883**，Δ +0.003 [+0.001, +0.006]。
- 不過 val 為 **0.879 [0.860, 0.896]**，相對 Exp N 的 0.881 是 Δ −0.003 [−0.007, +0.001]，沒有變好。
- 年齡配對 val 0.865（Exp N 0.868）。陰性 Spearman(分數, 年齡) val 0.246（Exp N 0.235）。
- 膽囊遮罩缺失的陽性 val 0.747 vs 0.776，Δ −0.029 [−0.059, −0.002]。
- **判定：沒有新最佳，膽結石主版本維持 Exp N（G5c＋U，val 0.881）。** OOF 的小幅增益沒有在 val 重現，而且最需要改善的膽囊缺失子群反而變差。

## 1. 方法
- 腳本 `scripts/gf_stack.py` 由 `nu_gs_stack.py` 複製修改：特徵定義、7 個 LR／GBM 候選、GS1 folds、bootstrap 程式碼都相同。
- 重現檢查：N_U 與 Exp N 的相關係數 1.000，G6c 與 final_cmp 的相關係數 1.000。
- 兩個特徵 frame：
  - frame 0：原始 3 mm 特徵，搭配 gs5 gbx。
  - frame 1：用 GS6 的 `override_feat.csv` 替換 5,034 例的 hu／ag／g1 欄位。
- 變體：
  - **N_U**（REF）：Exp N 最佳，frame 0。
  - **G6c**：frame 1，V4＋gs6/gbx＋g3b_livfb。
  - **(a) a_G6c_U**：G6c＋單元頭 logit gbn_U。
  - **(b) b_N_U_ov**：Exp N 的特徵組套用到 frame 1（GS6 override），gbx 仍用 gs5。
  - **(c) c_avg**：N_U 與 G6c 各自以 train OOF 的平均／標準差做 z-score 後取平均，相同常數直接套到 val。不調任何參數。
- 只依 train OOF 選擇。val 只評一次，配對分層 bootstrap 2,000 次。
- 子群一律用**原始 3 mm 遮罩**定義：膽囊 < 100 vox 為缺失；> 100 HU 連通塊 ≥ 2 為可見。
- 不使用年齡／性別輸入，也不使用其他疾病的 logit。

## 3. 解讀
1. 兩個模型高度相關（約 0.95），能互補的空間很小。所有組合在 OOF 上只多 +0.001～+0.003，val 全部持平或下降。
2. 只要加入 GS6 override 特徵（G6c、(a)、(b)），val 的膽囊缺失子群就下降（−0.04～−0.07）。Exp N 的單元已經用 GS6 遮罩決定 crop 中心，再加上 GS6 的 HU 特徵似乎在這 46 例上過擬合。但 OOF 的膽囊缺失子群反而略升（0.717 → 0.73），方向不一致，屬於小樣本雜訊範圍。
3. 年齡沒有變成捷徑：所有變體的陰性 Spearman 都在 0.22–0.25，年齡配對 AUROC 與整體 AUROC 同步。
4. 建議：**維持 Exp N（G5c＋U）為膽結石主版本**。若要把 (c) 當作穩健性備案，它的 train OOF 最高、val 差距不顯著，但部署時要同時跑兩條管線，成本加倍。
